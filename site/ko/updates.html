    업데이트

    앱이 새 버전을 찾아 설치하는 방법과, GitHub가 느린 곳에서 할 일을 설명합니다.

    이 페이지의 내용
    • 새 버전이 나오면
    • 안정 버전과 프리릴리스 버전
    • GitHub가 느리거나 막혀 있다면

    새 버전이 나오면

    앱은 시작할 때마다 GitHub에 새 버전이 있는지 확인합니다. 새 버전이 있으면 버전과 바뀐 내용을 내 언어로 보여 주는 창이 나타납니다.

    • 지금 업데이트는 새 버전을 내려받고 앱을 닫은 뒤 파일을 바꾸고 다시 실행합니다. 설정, 프리셋, 라이브러리는 그대로 남습니다.
    • 릴리스 페이지는 브라우저에서 릴리스를 엽니다.
    • 나중에는 창을 닫습니다.

    안정 버전과 프리릴리스 버전

    정보 → 업데이트 채널:

    • 안정 버전: 정식 릴리스만 받습니다. 앱이 잘 동작하기만 하면 된다면 이것을 고르세요.
    • 프리릴리스 버전: 정식 릴리스 전에 나오는 테스트 빌드도 받습니다. 새 기능을 더 빨리 받는 대신, 가끔 새 문제도 함께 받습니다.

    업데이트 확인을 누르면 바로 확인합니다. 시작 시 업데이트 확인으로 자동 확인을 끌 수 있습니다.

    GitHub가 느리거나 막혀 있다면

    중국 본토를 비롯한 일부 지역에서는 GitHub가 느리거나 접속되지 않습니다. 정보 → GitHub 접속 방식에는 다음 선택지가 있습니다.

    • GitHub에 직접 연결: 기본값입니다.
    • 미러 사이트(가장 빠른 곳 자동 선택): 앱이 알려진 미러 사이트 여덟 곳을 측정해 가장 빠른 곳을 씁니다. 사이트 속도 측정을 누르면 각 사이트가 어떻게 응답했는지 보여 줍니다.
    • 직접 지정한 미러 사이트: GitHub를 중계하는, 내가 믿을 수 있는 사이트의 주소를 넣습니다.

    응답하는 사이트가 하나도 없으면 다른 선택지를 안내하는 창이 나타납니다.

    주의

    앱은 업데이트할 때 자기 파일을 바꾸므로, 앱 폴더에 쓰기 권한이 있어야 합니다. Program Files 아래 폴더는 대개 쓸 수 없으며, 그럴 때는 앱이 알려 줍니다. 앱을 내 폴더로 옮기거나, 릴리스 페이지에서 새 zip을 내려받아 파일을 직접 바꾸세요. 어느 쪽이든 설정은 그대로 남습니다.
