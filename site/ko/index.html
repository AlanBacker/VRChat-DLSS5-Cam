    VRChat DLSS5 Cam

    VRChat 카메라와 내 사진, 동영상을 NVIDIA DLSS 5로 처리해 저장하는 무료 Windows 앱입니다.

    무엇을 하는 앱인가요

    VRChat DLSS5 Cam은 이미지를 NVIDIA DLSS 5 뉴럴 렌더링으로 처리합니다. 신경망이 빛과 피부, 재질을 다시 렌더링합니다. 결과를 원본과 나란히 보고 파일로 저장할 수 있습니다.

    • VRChat 실시간. VRChat 카메라가 앱으로 화면을 보냅니다. Ctrl+Alt+P를 누르면 VRChat을 앞에 둔 채로 무손실 PNG가 저장됩니다.
    • 사진과 동영상. 스크린샷이나 녹화 영상을 열고 느낌을 조정한 뒤 PNG, MP4, GIF, APNG, WebP로 저장합니다.
    • 여러 파일을 한 번에. 연 파일은 모두 라이브러리에 들어갑니다. 몇 개만 골라서, 또는 전부를 한 번에 처리할 수 있습니다.
    • 안심하고 쓸 수 있습니다. 앱은 VRChat을 건드리지 않고 모드도 필요 없습니다. 이미지는 내 컴퓨터 밖으로 나가지 않습니다.

    모든 릴리스와 릴리스 노트

    참고

    내 그래픽 카드가 무엇인지 모르겠다면 작업 관리자를 열고 성능에서 GPU를 클릭하세요. 오른쪽 위에 카드 이름이 표시됩니다.

    가이드

    다운로드부터 첫 이미지 저장까지, 이어서 실시간 카메라, 동영상, 일괄 처리까지 짧은 단계로 안내합니다. 각 단계는 몇 분이면 끝납니다.

    1. 1설치그래픽 카드에 맞는 파일을 내려받아 압축을 풀고 앱을 실행합니다.
    2. 2첫 이미지사진을 열어 DLSS 5 결과와 비교하고 저장합니다. VRChat을 실행하지 않아도 됩니다.
    3. 3실시간 카메라VRChat 카메라 화면을 앱으로 보내 DLSS 5를 실시간으로 보고, 단축키로 사진을 저장합니다.
    4. 4동영상동영상이나 GIF 애니메이션을 열고 원하는 구간을 골라 DLSS 5를 적용해 저장합니다.
    5. 5라이브러리파일을 모아 여러 개를 한 번에 처리하고, 파일 하나에만 따로 값을 주거나 회전하고 잘라 냅니다.
    6. 6프리셋마음에 드는 느낌에 이름을 붙여 보관하고, 모든 변경을 하나씩 되돌립니다.
    7. 7저장저장 폴더와 파일 이름을 정하고, 투명도를 유지하고, 앱 자체의 파일을 찾습니다.
    8. 8업데이트앱이 새 버전을 찾아 설치하는 방법과, GitHub가 느린 곳에서 할 일을 설명합니다.

    레퍼런스

    필요할 때 찾아보세요.

    • 동작 원리DLSS 5가 이미지에 무엇을 하는지, 앱에서 무엇을 받는지, 추가 패스는 무엇을 위한 것인지 설명합니다.
    • 설정사이드바의 모든 컨트롤을 앱에 표시되는 순서대로, 섹션별로 정리했습니다.
    • 단축키앱의 모든 키와 마우스 동작을 한 페이지에 모았습니다.
    • 명령줄파일을 열고, 창 없이 처리하고, 시험 실행을 스크립트로 만듭니다. 터미널을 좋아하는 분을 위한 페이지입니다.
    • MCPMCP 클라이언트, 스크립트, 챗봇이 이 컴퓨터나 다른 컴퓨터에서 앱을 조작하게 합니다.
    • LinuxNVIDIA 카드가 있는 Linux에서 Proton으로 GeForce 에디션을 실행합니다. 사진과 동영상을 쓸 수 있고, 실시간 카메라는 없습니다.
    • RadeonRadeon 에디션과 DLSS-NR-on-AMD로 AMD Radeon RX 7000이나 9000에서 DLSS 5를 실행합니다.
    • 문제 해결VRChat 화면이 오지 않을 때부터 카드가 느릴 때까지, 메시지의 뜻과 해결 방법을 정리했습니다.
    • 자주 묻는 질문가장 많이 받는 질문에 짧게 답합니다.
    • 개인정보와 라이선스앱이 네트워크로 보내는 것(거의 없습니다)과, 앱과 구성 요소의 라이선스를 설명합니다.
    • 변경 내역릴리스마다 바뀐 내용을 최신순으로 보여 줍니다.
