    문제 해결

    VRChat 화면이 오지 않을 때부터 카드가 느릴 때까지, 메시지의 뜻과 해결 방법을 정리했습니다.

    실시간 카메라

    "Spout 송신자를 찾을 수 없음"

    화면을 보내는 프로그램이 없습니다. VRChat에서 카메라를 열고 Stream 모드로 바꾼 뒤 Spout Stream을 켜세요. 카메라는 열어 둔 채로 있어야 합니다.

    "VRChat Spout 스트림 대기 중…"

    송신자는 실행 중이지만, 선택한 송신자가 아직 화면을 보내지 않았습니다. VRChat 카메라가 열려 있는지 확인하거나, 소스 → Spout 송신자에서 다른 송신자를 고르세요.

    DLSS 5

    "그래픽 드라이버 업데이트가 필요합니다"

    DLSS 5에는 GeForce 드라이버 616.56 이상이 필요합니다. 알림에서 드라이버 다운로드를 클릭하고, 최신 드라이버를 설치한 뒤 앱을 다시 실행하세요. 그래픽 드라이버

    "런타임 파일이 없습니다"

    zip 파일의 압축이 다 풀리지 않았습니다. 모두 압축 풀기로 새 폴더에 다시 압축을 푸세요. runtimes\blackwell\nvngx_dlssnr.dll과 runtimes\universal\nvngx_dlssnr.dll 파일이 VRChatDLSS5Cam.exe 옆에 있어야 합니다.

    DLSS 5가 시작되지 않습니다

    앱은 다른 내장 빌드를 알아서 시도하고, 그 사실을 알려 줍니다. 둘 다 시작되지 않으면:

    1. 최신 그래픽 드라이버를 설치합니다.

    2. 앱을 다시 실행합니다.

    3. 그래도 안 되나요? 정보 → 문제 신고를 누르고 log.txt를 첨부하세요.

    동작 중인데 이미지가 검거나 바뀌지 않습니다

    앱은 모든 DLSS 5 프레임을 입력과 비교하고, 런타임이 검은 이미지나 바뀌지 않은 이미지를 돌려주면 경고합니다. DLSS 5(DLSSNR) 사용을 껐다가 다시 켜세요. 강도가 0이면 이미지가 바뀌지 않는 것이 정상이며, 경고도 나타나지 않습니다.

    속도

    실시간 화면이 느립니다

    다음을 하나씩 시도해 보세요.

    1. DLAA 프리패스와 DLSS 초해상도를 켜 두었다면 끕니다.

    2. 뉴럴 패스 해상도를 낮춥니다. 예를 들면 긴 변 최대 1440 px입니다.

    3. 처리 속도 상한을 설정합니다.

    4. 촬영 시에만 뉴럴 패스 실행을 켭니다. 미리보기는 쉬고, 사진에는 그래도 DLSS 5가 적용됩니다.

    이 컨트롤은 고급이 켜져 있을 때 표시됩니다. 플로우 그리드는 4 px로 두세요. 2 px 또는 1 px로 줄이면 4K에서 부담이 훨씬 커집니다.

    "그래픽 장치가 손실되었습니다"

    그래픽 드라이버가 카드를 재설정했습니다. Windows는 작업 하나당 카드에 약 2초를 주는데, 오랫동안 부하가 가득 찬 카드는 이 시간을 넘길 수 있습니다. 예를 들어 VRChat과 DLSS 5가 큰 크기로 같은 카드에서 실행될 때입니다. 앱은 스스로 다시 시작하고, 그 사실을 알려 줍니다.

    같은 일이 또 생기면 부하를 줄이세요. 처리 속도 상한, 더 작은 뉴럴 패스 해상도, 더 작은 출력 크기, VRChat의 프레임률 제한 같은 방법이 있습니다. 최신 그래픽 드라이버도 시도해 볼 만합니다.

    동영상

    동영상 미리보기가 검습니다

    많은 동영상이 검은 화면에서 서서히 밝아지며 시작합니다. 미리보기는 그런 프레임을 건너뛰고, 이미지 아래에 그 사실을 표시합니다. 타임라인이나 화살표 키로 앞으로 이동하세요.

    동영상이 열리지 않거나 MP4로 저장할 수 없습니다

    어떤 형식을 쓸 수 있는지는 Windows가 정합니다. HEVC 파일에는 Microsoft Store의 HEVC 비디오 확장이 필요하고, Windows N 에디션에는 Media Feature Pack이 필요합니다. 그래픽 카드가 거부하는 파일은 소스 → 하드웨어 디코딩을 끄면 열리기도 합니다. 출력으로는 PNG 시퀀스가 언제나 동작합니다.

    업데이트

    업데이트를 설치할 수 없습니다

    앱 폴더에 쓰기 권한이 있어야 하는데, Program Files 아래 폴더는 대개 쓸 수 없습니다. 앱을 내 폴더로 옮기거나, 릴리스 페이지에서 새 zip을 내려받아 파일을 직접 바꾸세요. 설정과 라이브러리는 그대로 남습니다.

    업데이트 확인이 실패합니다

    GitHub가 느리거나 막혀 있는 곳에서는 정보 → GitHub 접속 방식 → 미러 사이트(가장 빠른 곳 자동 선택)를 고르세요. 업데이트

    앱이 닫히거나 충돌했을 때

    다음에 실행할 때 앱은 지난 세션이 정상적으로 끝나지 않았다는 것을 알아챕니다. 창이 나타나 GitHub에 신고(이슈 양식이 미리 채워진 채로 열립니다)와 로그 폴더 열기를 제안합니다.

    로그 폴더는 %LOCALAPPDATA%\VRChatDLSS5Cam입니다. 신고할 때 log-crash.txt와 crash.txt를 첨부하세요. 정보 → 문제 신고도 언제든 쓸 수 있습니다.

    팁

    신고하기 전에 신고 양식을 한 번 읽어 보세요. 앱 버전과 그래픽 카드가 채워져 있으며, 제출하기 전까지는 아무것도 전송되지 않습니다.
