    更新日志

    每个版本的变化，最新的在前。

    版本 2.0.3

    新增文档网站，程序中的文档按钮都会打开它。能运行 v2.0.2 的电脑可以直接运行 v2.0.3：设置文件、预设、MCP 工具和命令行都没有变化。

    新增

    • 文档网站：https://alanbacker.github.io/VRChat-DLSS5-Cam/。
    • “关于”分节中的文档按钮和顶栏的 ? 按钮会以界面语言打开网站。

    GitHub 上的完整发布说明

    版本 2.0.2

    正式版，在 v2.0.1 的基础上修正了一些问题，并增加了几项小功能。能运行 v2.0.1 的电脑可以直接运行 v2.0.2：设置文件、预设、MCP 工具和命令行都没有变化，两个更新通道上的程序都会主动提示这个版本。

    修正

    • 切换深度来源后，深度视图能恢复显示。
    • 深度网络只在需要时运行。
    • 再开一个使用同一设置文件夹的窗口，不会再清空日志。
    • 脚本运行不再干扰崩溃提示。

    新增

    • 显卡驱动过旧时的提醒。
    • 日志会保留下来。
    • 崩溃后的提示。
    • GitHub 上的 issue 表单。
    • 以你的语言显示发布说明。

    GitHub 上的完整发布说明

    更早的版本列在 GitHub 上。
