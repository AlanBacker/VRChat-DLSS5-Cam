**更新是怎样完成的**

1. **启动时检查**: GitHub 或镜像站
2. **有新版本**: 发布说明用你的语言显示
3. **立即更新**: 下载并解压
4. **重新启动**: 设置和素材库保持不变

## 新版本

程序每次启动时，都会向 GitHub 查询是否有更新的版本。如果有，会弹出一个窗口，用你的语言显示版本号和更新内容。

- **立即更新**会下载新版本，关闭程序，替换程序文件，然后重新启动。你的设置、预设和素材库都保持原样。
- **查看发布页**在浏览器中打开这个版本的发布页。
- **以后再说**关闭窗口。

## 稳定版还是预览版

**关于** → **更新通道**：

- **稳定版**：只有正式版。如果你只想让程序好好工作，就选这个。
- **预览版**：还包括正式版之前的测试版本。你能更早用上新功能，有时也会遇到新问题。

**检查更新**会立即查询一次。**启动时检查更新**可以关闭自动检查。

## GitHub 访问缓慢或被屏蔽时

在一些地区（包括中国大陆），访问 GitHub 很慢甚至无法访问。**关于** → **GitHub 访问方式**提供以下选项：

- **直连 GitHub**：默认选项。
- **加速镜像站（自动测速选最快）**：程序对 8 个已知镜像站测速，然后使用最快的那个。**测速**会显示每个站点的响应情况。
- **自定义镜像站**：填入一个你信任的、能中转 GitHub 的站点地址。

所有站点都没有响应时，会弹出一个窗口，让你改选其他方式。

<Warning>

程序更新时会替换自己的文件，所以它所在的文件夹必须可写。`Program Files` 下的文件夹通常不可写，程序会提示这一点。请把程序移到你自己的文件夹，或者从发布页下载新的压缩包，手动替换文件。无论哪种方式，设置都会保留。

</Warning>
