## 通用

| 按键 | 作用 |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>P</kbd> | 实时模式：拍照，即使 VRChat 在前台也有效。图片或视频模式：处理并保存。可以在**拍照** → **全局热键**中修改。 |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> | 撤销上一次对设置或素材库的更改。 |
| <kbd>Ctrl</kbd>+<kbd>Y</kbd> · <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | 重做。 |
| <kbd>F11</kbd> | 全屏显示画面。按 <kbd>Esc</kbd> 或 <kbd>F11</kbd> 退出。 |
| <kbd>Tab</kbd> · <kbd>Shift</kbd>+<kbd>Tab</kbd> | 移到下一个或上一个控件。方向键永远不会在控件之间移动。 |
| 在搜索框中按 <kbd>Esc</kbd> | 清空搜索。 |
| 在 AI 问答面板中按 <kbd>Esc</kbd> | 关闭面板。[AI 问答](/zh/ai-qa) |

## 画面

| 鼠标 | 作用 |
|---|---|
| 在画面上滚动鼠标滚轮 | 以指针为中心缩放。 |
| 拖动画面 | 在放大后的画面中四处移动。 |
| 双击 | 回到完整画面。 |
| 拖动白线 | 移动分隔线（在**分割对比**视图中）。 |
| 裁切时按 <kbd>Enter</kbd> · <kbd>Esc</kbd> | 应用裁切，或者取消。 |

## 视频

| 按键 | 作用 |
|---|---|
| <kbd>Space</kbd> | 播放或暂停。 |
| <kbd>←</kbd> · <kbd>→</kbd> | 后退或前进一帧。按住 <kbd>Shift</kbd>：十帧。 |
| <kbd>Home</kbd> · <kbd>End</kbd> | 跳到开头或结尾。 |
| <kbd>I</kbd> · <kbd>O</kbd> | 设置要保存的片段的起点或终点。 |

## 素材库

| 操作 | 作用 |
|---|---|
| 单击缩略图 | 只选中这个文件。 |
| 双击缩略图 | 在预览中打开它。 |
| <kbd>Ctrl</kbd> + 单击 | 把一个文件加入选择，或从选择中去掉。 |
| <kbd>Shift</kbd> + 单击 | 从上次单击的位置起扩展选择。 |
| 在空白处拖动 | 拉出一个选择框。单击空白处会取消选择。 |
| 在缩略图上按右键 | 文件的菜单：单独参数、在资源管理器中显示、移除。 |
| <kbd>Ctrl</kbd>+<kbd>A</kbd> | 选中所有文件（鼠标位于素材库上时）。 |
| <kbd>Delete</kbd> | 把选中的文件移出素材库。文件仍保留在磁盘上。 |

## 布局

| 操作 | 作用 |
|---|---|
| 单击侧栏旁或素材库上方的空隙 | 折叠或展开那个面板。 |
| 拖动空隙边缘的细线 | 改变侧栏的宽度或素材库的高度。程序会记住这两个尺寸。 |
