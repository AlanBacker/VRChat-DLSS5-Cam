## 实时相机

### “未找到 Spout 发送端”

没有程序在发送画面。在 VRChat 中打开**相机**，切换到 **Stream** 模式，并打开 **Spout Stream**。相机必须保持打开。

### “等待 VRChat Spout 串流…”

有发送端在运行，但所选的发送端还没有送来画面。检查 VRChat 相机是否打开，或者在**视频源** → **Spout 发送端**中选择另一个发送端。

## DLSS 5

### “需要更新显卡驱动”

DLSS 5 需要 616.56 或更新的 GeForce 驱动。点击提示中的**下载驱动**，安装最新驱动，然后重新启动程序。[显卡驱动](/zh/install#driver)

### “运行库文件缺失”

压缩包没有完整解压。用**全部解压缩**把它重新解压到一个新文件夹。`runtimes\blackwell\nvngx_dlssnr.dll` 和 `runtimes\universal\nvngx_dlssnr.dll` 这两个文件应该位于 `VRChatDLSS5Cam.exe` 旁边。

### DLSS 5 启动失败

程序会自动改试另一份附带的运行库，并告诉你。如果两份都无法启动：

1. 安装最新的显卡驱动。
2. 重新启动程序。
3. 仍然失败？点击**关于** → **反馈问题**，并附上 `log.txt`。

### 显示“运行中”，但画面全黑或没有变化

程序会把每一帧 DLSS 5 的结果与输入对比，运行库返回全黑或没有变化的画面时就发出警告。把**启用 DLSS 5（DLSSNR）**关闭再打开。**强度**为 0 时画面不变是正常的，也不会出现警告。

## 速度

### 实时画面很慢

逐一试试下面的方法：

1. 如果打开了 **DLAA 预处理**和 **DLSS 超分辨率**，把它们关闭。
2. 选择更小的**神经渲染分辨率**，例如**长边不超过 1440 像素**。
3. 设置**处理帧率上限**。
4. 打开**仅拍照时运行神经渲染**：预览会休息，照片依然会经过 DLSS 5。

这些控件在**高级**打开时显示。**光流网格**保持 4 px 即可：2 px 和 1 px 在 4K 下的开销要大得多。

### “图形设备已丢失”

显卡驱动重置了显卡。Windows 给每项显卡任务大约两秒，长时间满载的显卡可能会超时，例如 VRChat 和 DLSS 5 在同一块显卡上以很大的尺寸运行时。程序会自动重新启动，并告诉你发生了什么。

如果再次出现，请降低负载：设置处理帧率上限、调小神经渲染分辨率、调小输出尺寸，或者在 VRChat 中限制帧率。也值得试试更新显卡驱动。

## 视频

### 视频预览全黑

许多视频以黑场淡入开始。预览会跳过这些帧，并在画面下方说明。用时间轴或方向键往后移动即可。

### 视频打不开，或无法保存为 MP4

哪些格式能用，由 Windows 决定。HEVC 文件需要 Microsoft Store 中的 **HEVC 视频扩展**，Windows 的 N 版本需要 **Media Feature Pack**。对于显卡拒绝解码的文件，关闭**视频源** → **硬件解码**会有帮助。输出选择 **PNG 序列**总是可行的。

## 更新

### 无法安装更新

程序所在的文件夹必须可写，而 `Program Files` 下的文件夹通常不可写。请把程序移到你自己的文件夹，或者从发布页下载新的压缩包，手动替换文件。设置和素材库都会保留。

### 检查更新失败

如果 GitHub 访问缓慢或被屏蔽，选择**关于** → **GitHub 访问方式** → **加速镜像站（自动测速选最快）**。[更新](/zh/updates#mirror)

## AI 问答

### “无法加载 AI 问答”

AI 问答需要连接互联网。请检查网络连接，然后点击面板中的**重试**。旁边的**打开文档**则会改为在浏览器中打开这些页面。

### “AI 问答暂时不可用”

可能是本项目 AI 问答的每月额度已经用完，或者 Mintlify 的服务出现故障。额度会在下个月恢复。在此之前，这些页面同样能解答这些问题：点击提示中的**打开文档**就能打开它们。

面板中的其他提示，以及各自的应对方法：[问题没有得到回答时](/zh/ai-qa#notices)

### 点击“问 AI”打开的是浏览器

程序内的面板需要 Microsoft Edge WebView2 运行时。没有它的电脑上，以及在 Linux 软件包中，**问 AI** 会改为在浏览器中打开 AI 问答。要在 Windows 上使用程序内的面板，请安装该运行时，然后重新启动程序。[AI 问答](/zh/ai-qa#browser)

## 程序关闭或崩溃了

下次启动时，程序会发现上次运行没有正常结束。弹出的窗口提供**到 GitHub 反馈**（打开一份已经填好信息的 issue 表单）和**打开日志文件夹**。

日志文件夹是 `%LOCALAPPDATA%\VRChatDLSS5Cam`。请在反馈中附上 `log-crash.txt` 和 `crash.txt`。**关于** → **反馈问题**也随时可用。

<Tip>

反馈之前，请把表单通读一遍。表单中已经填好了程序版本和你的显卡，在你提交之前，不会发送任何内容。

</Tip>
