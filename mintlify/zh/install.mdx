## 需要准备什么

- Windows 10（21H2 或更新）或 Windows 11，64 位。
- 一块 NVIDIA GeForce RTX 显卡：RTX 20、30、40 或 50 系列。
  AMD Radeon RX 7000 或 9000 可以使用 [Radeon 版](/zh/radeon)。
- 使用实时相机还需要 VRChat，桌面模式或 VR 均可。

别的都不需要。DLSS 5 运行库已经在下载包里，分为 RTX 50 一份和 RTX 40、30、20 一份。程序会自己选择合适的那一份。

## 下载并解压

1. 打开[下载区](/zh#download)，选择与显卡对应的文件。
   GeForce 显卡对应的是 `VRChatDLSS5Cam-win64.zip`。
2. 右键点击压缩包，选择**全部解压缩**。选一个你自己的文件夹，例如**文档**。

   <Check>出现一个新文件夹，里面有 `VRChatDLSS5Cam.exe`。</Check>

3. 双击 `VRChatDLSS5Cam.exe`。

   <Check>先出现一张带程序图标的小卡片，随后打开主窗口。</Check>

<Warning>

不要直接在压缩包里启动程序，也不要把它放在 `Program Files` 下。程序更新时会替换自己的文件，而在需要管理员权限的文件夹里，它做不到这一点。

</Warning>

<Note>

本程序没有使用付费证书签名，所以 Windows 可能弹出一个蓝色窗口，说它已保护你的电脑。点击**更多信息**，再点击**仍要运行**。源代码在 GitHub 上公开。

</Note>

## 设置向导

首次启动时会打开一个简短的设置向导，共五页：

1. **欢迎**：语言和外观（**跟随系统**、**深色**或**浅色**）。
2. **GitHub 访问方式**：程序怎样连接 GitHub 获取更新。保持**直连 GitHub** 即可。如果 GitHub 访问缓慢或被屏蔽，选择**加速镜像站（自动测速选最快）**。
3. **程序是怎样工作的**
4. **各项设置的用途**
5. **在哪里能找到什么**

**下一步**继续，**跳过**关闭向导。以后想再看：**关于** → **设置向导**。

## 显卡驱动

DLSS 5 需要 **616.56** 或更新的 GeForce 驱动。程序每次启动都会检查驱动，版本较旧时会提醒你：

<Frame>
  <img src="https://alanbacker.github.io/VRChat-DLSS5-Cam/assets/img/gen/zh/driver-notice.webp" alt="“需要更新显卡驱动”提示：横条左侧是已安装的驱动 536.99，右侧是所需的 616.56，下方是“关闭”和“下载驱动”按钮" width="576" />
</Frame>

1. 点击**下载驱动**，浏览器会打开 NVIDIA 的下载页面。
2. 为你的显卡安装最新驱动。
3. 重新启动程序。

   <Check>提示不再出现，**DLSS 5 神经渲染**显示**运行中**。</Check>

驱动较旧时，其他功能照常可用：查看画面、拍照和处理视频。只有 DLSS 5 无法启动。

<Tip>

提示中的**不再显示**会关闭这项检查。**关于** → **启动时检查显卡驱动**可以重新打开它。

</Tip>
