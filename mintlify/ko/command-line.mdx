명령줄은 몰라도 괜찮습니다. 더블클릭하면 평소의 창이 열립니다. 명령줄은 스크립트, 예약 실행, 시험을 위해 있습니다.

```
VRChatDLSS5Cam.exe [file] [options]
```

파일 이름만 주면 그 이미지나 동영상을 엽니다. 탐색기의 **연결 프로그램**과 같은 동작입니다.

## 예시

창 없이 파일 두 개를 처리해 `D:\out`에 저장하고, 동영상은 HEVC로 저장합니다.

```
VRChatDLSS5Cam.exe --headless --add "D:\shots\a.png" --add "D:\shots\clip.mp4" --set videoMatchSource=0 --set videoOutput=1 --process "D:\out"
```

동영상의 1:00부터 1:10까지 10초를 처리해 저장 폴더에 저장합니다.

```
VRChatDLSS5Cam.exe --headless --open "D:\clip.mp4" --in 1:00 --out 1:10 --process
```

동영상의 30초 지점을 연 창을 일본어 인터페이스와 라이트 테마로 캡처한 뒤 종료합니다.

```
VRChatDLSS5Cam.exe --window 1600x900 --lang ja --set theme=2 --open "D:\clip.mp4" --seek 30 --screenshot 6 "D:\ui.png" --exit-after 8
```

## 옵션

| 옵션 | 역할 |
|---|---|
| `--open <file>` | 이미지나 동영상을 열고 라이브러리에 추가합니다. GIF, APNG, WebP 애니메이션은 동영상으로 취급합니다. |
| `--add <file>` | 파일을 열지 않고 라이브러리에 추가합니다. 여러 번 쓸 수 있습니다. |
| `--seek <time>` | 동영상: 이 시각의 프레임을 표시합니다. `m:ss`, `h:mm:ss`, 초 단위를 쓸 수 있습니다. |
| `--play` | 동영상: 재생을 시작합니다. |
| `--in <time>` · `--out <time>` | 동영상: 처리할 구간입니다. 소리도 포함됩니다. |
| `--process [folder]` | 현재 설정으로 라이브러리(또는 열린 파일)를 처리한 뒤 종료합니다. `folder`에 저장하며, 지정하지 않으면 저장 폴더에 저장합니다. |
| `--set <key>=<value>` | `settings.ini`에 쓰이는 이름으로 설정 하나를 이번 실행에서만 바꿉니다. 아래를 참고하세요. |
| `--lang <en\|zh\|ja\|ko\|auto>` \{#lang\} | 이번 실행의 인터페이스 언어입니다. |
| `--window <W>x<H>` | 이 창 크기로 시작합니다. |
| `--screenshot <seconds> <file.png>` | 시작하고 이 초만큼 지난 뒤 창을 이미지로 저장합니다. 여러 번 쓸 수 있습니다. |
| `--exit-after <seconds>` | 이 초만큼 지난 뒤, 스크린샷과 저장 파일이 모두 기록되면 종료합니다. |
| `--headless` | 창을 띄우지 않습니다. 저장과 스크린샷은 평소처럼 동작하며, 할 일이 끝나면 앱이 종료합니다. |
| `--data-dir <folder>` | 설정, 프리셋, 로그를 `%LOCALAPPDATA%\VRChatDLSS5Cam` 대신 이 폴더에 둡니다. |
| `--mcp` | MCP 클라이언트용 브리지입니다. [MCP](/ko/mcp) |
| `--mcp-port <port>` | 이번 세션에서 이 포트로 MCP 서버를 실행합니다. |
| `--update` | 선택한 채널에서 새 버전을 찾아 설치합니다. |
| `--edition <geforce\|amd>` \{#edition\} | 업데이트와 같은 방식으로 다른 에디션으로 바꿉니다. |

## 이번 실행에만 쓰는 설정

`--set`에는 `settings.ini`에 쓰이는 이름을 씁니다. 명령줄로 준 값은 저장되지 않습니다. 쓸모 있는 키 몇 가지는 다음과 같습니다.

| 키 | 값 |
|---|---|
| `nrIntensity` | `0`~`2`. 예: `--set nrIntensity=1.5`. |
| `videoMatchSource` | `1`(기본값)은 소스를 따르고, `0`은 아래 세 키를 씁니다. |
| `videoOutput` | `0` MP4 H.264, `1` MP4 HEVC, `2` PNG 시퀀스, `3` GIF, `4` APNG, `5` WebP. |
| `videoBitrate` · `webpQuality` | MP4 비트레이트, 그리고 WebP 품질(`50`~`100`). |
| `keepAudio` | `0`이면 소리를 뺍니다. |
| `outputName` · `captureName` | 파일 이름 템플릿입니다. [쓸 수 있는 단어](/ko/saving#names) |
| `customResolution` · `customWidth` · `upscaleMode` | 업스케일: `--set customResolution=1 --set customWidth=3840 --set upscaleMode=0`(`0` DLSS 초해상도, `1` 리샘플링). |
| `theme` | `0` Windows 설정을 따름, `1` 다크, `2` 라이트. |
| `updateCheck` · `updateChannel` | 시작 시 확인(`1` 켬), 채널(`0` 안정 버전, `1` 프리릴리스 버전). |
| `driverCheck` | 시작 시 드라이버 알림(`1` 켬). |
| `reopenLast` | 시작할 때 마지막 파일 다시 열기(`0` 끔). |

## 종료 코드

| 코드 | 의미 |
|---|---|
| `0` | 모두 성공했습니다. |
| `1` | 처리하지 못한 파일이 있습니다. |
| `2` | 앱이 충돌했거나(`crash.txt`가 기록됩니다) 그래픽 장치가 손실되었습니다. |

로그 파일 `log.txt`에는 모든 명령줄 동작이 기록되므로, 실패한 실행을 나중에 다시 읽어 볼 수 있습니다. Linux에서는 `vrchat-dlss5-cam` 실행 스크립트가 같은 옵션을 받습니다. [Linux](/ko/linux)

시험용 옵션을 포함한 전체 목록은 GitHub의 [COMMAND_LINE.md](https://github.com/AlanBacker/VRChat-DLSS5-Cam/blob/main/docs/COMMAND_LINE.md)에 있습니다.
