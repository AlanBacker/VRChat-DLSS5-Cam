## 파일은 내 컴퓨터에 남습니다

이미지, 동영상, 설정은 내 컴퓨터에 남습니다. 앱 자체에는 계정도, 추적도, 사용 통계도 없습니다. 모든 처리는 내 그래픽 카드에서 실행됩니다.

내가 쓴 내용을 보내는 것은 [AI Q&A](#app-ai-qa) 하나뿐입니다. AI Q&A를 열면 질문이 Mintlify로 전송됩니다. 파일은 함께 전송되지 않습니다.

## 앱이 인터넷에 접속할 때

앱은 다음 경우에만 인터넷에 연결합니다.

| 무엇 | 언제 | 어디로 |
|---|---|---|
| 업데이트 확인 | **시작 시 업데이트 확인**을 끄지 않았다면 시작할 때마다, 그리고 **업데이트 확인**을 클릭할 때. | GitHub, 또는 **GitHub 접속 방식**에서 고른 미러 사이트. |
| 업데이트 다운로드 | **지금 업데이트**를 클릭하거나 `--update` 또는 `--edition`을 실행할 때만. | 위와 같습니다. |
| 미러 사이트 측정 | **미러 사이트(가장 빠른 곳 자동 선택)**를 골랐을 때, 또는 **사이트 속도 측정**을 클릭할 때. | 알려진 미러 사이트 여덟 곳. |
| DLSS-NR-on-AMD | Radeon 에디션에서만: 최신 릴리스 조회, 그리고 버튼을 클릭했을 때의 설치 프로그램 다운로드. | GitHub에 있는 그 프로젝트의 릴리스 페이지, 또는 고른 미러 사이트. |
| AI Q&A | **AI에게 묻기**를 클릭한 뒤에만. 한 번 열린 패널은 앱을 닫을 때까지 불러온 상태로 남습니다. | 답변을 작성하는 Mintlify, 그리고 Mintlify의 봇 확인 기능인 hCaptcha. [자세히](#app-ai-qa) |
| 웹 주소로 지정한 MCP 작업 | MCP 서버가 켜져 있고, 클라이언트가 이미지나 동영상을 웹 주소로 지정한 작업을 보낼 때만. | 그 주소. [자세히](#mcp) |

명령줄에서 `--headless`나 `--process`로 실행할 때는 스스로 업데이트를 확인하지 않습니다.

**문서**, **드라이버 다운로드**, **문제 신고** 같은 버튼은 브라우저에서 페이지를 엽니다. **문제 신고**는 GitHub 양식에 앱 버전과 그래픽 카드를 채워 넣으며, 제출하기 전까지는 아무것도 전송되지 않습니다.

## 앱의 AI Q&A

상단 바의 **AI에게 묻기**를 누르면 이미지 옆 패널에 AI Q&A가 열립니다. AI Q&A는 이 문서를 바탕으로 질문에 답하며, 앱이 아니라 [Mintlify](https://mintlify.com)가 제공합니다. [AI Q&A](/ko/ai-qa)

- **열기 전에는 아무것도 시작되지 않습니다.** 앱은 패널을 그리는 Microsoft Edge WebView2를 **AI에게 묻기**를 처음 클릭할 때에만 시작합니다. 그 전에는 아무것도 전송되지 않습니다.
- **Mintlify로 가는 것.** 입력한 내용은 Mintlify로 전송되고 Mintlify가 답변을 작성하므로, 개인적인 내용은 넣지 마세요. 패널 맨 위의 안내 문구에도 그렇게 적혀 있습니다. Mintlify는 패널이 열렸을 때 같은 패널의 사용 이벤트도 받습니다. 봇을 막기 위해 Mintlify는 hCaptcha로 질문을 확인하며, 패널은 이 확인 기능을 hCaptcha 서버에서 불러옵니다.
- **여기에 남는 것.** 앱은 이미지, 동영상, 설정, 라이브러리를 절대 보내지 않습니다. 패널에 파일 첨부 기능이 있다면, 거기에 첨부하거나 붙여 넣은 것은 Mintlify로도 전송됩니다.
- **패널이 보관하는 것.** 쿠키와 저장 데이터이며, `%LOCALAPPDATA%\VRChatDLSS5Cam\webview2`, 또는 [`--data-dir`](/ko/command-line#data-dir)로 지정한 폴더 안의 `webview2`에 보관됩니다. 대화는 앱을 닫을 때까지 남습니다. 앱을 닫은 상태에서는 그 폴더를 지워도 됩니다. 다음에 열 때 앱이 새로 만듭니다.
- **로그에 기록되는 것.** 패널을 열고 닫은 때, 패널에서 생긴 오류, 답변마다의 HTTP 상태와 길이입니다. 질문이나 답변 본문은 절대 기록되지 않습니다. 답변에서 연 링크는 앱이 여는 다른 모든 페이지처럼 주소와 함께 기록됩니다.

Microsoft Edge WebView2 런타임이 없을 때와 Linux 패키지에서는 **AI에게 묻기**가 대신 이 사이트의 AI Q&A를 브라우저에서 엽니다. 그때는 [이 사이트의 AI Q&A](#ai-qa)의 설명이 적용됩니다.

## MCP 서버

MCP 서버는 직접 켜기 전까지 꺼져 있습니다. 켜면 내 컴퓨터에서만 연결을 받으며, 스스로 어딘가에 접속하지 않습니다. 작업은 파일을 보내는 대신 이미지나 동영상을 웹 주소로 지정할 수도 있으며, 그러면 앱이 그 주소에서 내려받습니다. 다른 컴퓨터는 **접근 범위**를 **로컬 네트워크**로 바꾸고 키를 준 다음에만 접속할 수 있습니다. [MCP](/ko/mcp)

## 이 사이트

이 페이지는 스스로 다른 서버에서 아무것도 불러오지 않습니다. 글꼴도, 스크립트도, 추적도 없습니다. 예외는 [AI Q&A](#ai-qa) 하나뿐이고, 그것도 직접 쓰려고 할 때만 불러옵니다. 고른 테마와 언어는 내 브라우저에만 저장됩니다.

## 이 사이트의 AI Q&A

**AI에게 묻기**를 클릭하면 AI Q&A가 열립니다. AI Q&A는 이 사이트의 페이지를 바탕으로 질문에 답하며, 이 사이트가 아니라 [Mintlify](https://mintlify.com)가 제공합니다.

페이지를 열어도 Mintlify에서는 아무것도 불러오지 않습니다. 상단 바나 검색 결과 맨 끝의 **AI에게 묻기**를 가리키거나 키보드로 그곳으로 이동하면 불러오기 시작해, 클릭할 때는 바로 쓸 수 있습니다. 입력한 내용은 Mintlify로 전송되고 Mintlify가 답변을 작성하므로, 개인적인 내용은 넣지 마세요. Mintlify는 패널이 열렸을 때 같은 패널의 사용 이벤트도 받습니다. 이 사이트는 여기에 페이지 주소를 넣지 말라고 Mintlify에 요청합니다. 봇을 막기 위해 Mintlify는 hCaptcha로 질문을 확인하며, 패널은 이 확인 기능을 hCaptcha 서버에서 불러옵니다. 이 브라우저 탭에서는 패널이 대화에 대한 참조를 보관하므로, 이어서 질문하면 그 대화가 이어집니다.
