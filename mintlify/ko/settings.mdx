| 설정 | 역할 |
|---|---|
| Spout 송신자 | 라이브 모드: 어떤 송신자의 화면을 받을지 정합니다. **자동(VRChat)**은 VRChat 카메라를 찾습니다. **새로 고침**은 송신자를 다시 찾습니다. |
| 이미지 열기… · 동영상 열기… | 이미지·동영상 모드: 파일을 엽니다. 옆의 ✕는 파일을 닫으며, 파일은 라이브러리에 남습니다. |
| 사용자 지정 출력 해상도 | 소스와 다른 크기로 저장합니다. **너비**와 **높이**를 정하고, **가로세로 비율 유지**로 모양을 유지합니다. 소스보다 크면 업스케일, 작으면 다운스케일입니다. |
| 업스케일 방식 | 이미지를 키우는 방법입니다. **DLSS 초해상도**: NVIDIA의 업스케일러가 디테일을 다시 만들고, 그다음 DLSS 5가 큰 이미지를 처리합니다. 훨씬 느리고 비디오 메모리가 더 필요합니다. **리샘플링(Catmull-Rom)**: 단순한 필터입니다. |
| 원본 영상 규격에 맞추기 | 동영상. 처음에는 켜져 있으며, 결과가 소스의 형식, 프레임률, 비트레이트를 따릅니다. GIF, APNG, WebP 애니메이션은 반복 횟수를 유지한 채 원래 형식으로 돌아옵니다. |
| 저장 형식 | 원본 영상 규격에 맞추기가 꺼져 있을 때: **MP4 (H.264)**, **MP4 (HEVC)**, **PNG 시퀀스**, **GIF**, **APNG**, **WebP** 중에서 고릅니다. [어떤 형식을 고를까](/ko/videos#format) |
| 비트레이트 | MP4: 평균 비트레이트로, 5~200 Mbit/s입니다. 40이면 4K에서도 압축 흔적이 거의 없습니다. |
| 오디오 유지 | MP4: 소리를 결과에 복사합니다. |
| WebP 품질 | WebP 애니메이션: 50~100. 높을수록 화질이 좋고 파일이 커지며, 100은 무손실입니다. |
| 하드웨어 디코딩 | <sup>고급</sup> 그래픽 카드로 동영상을 디코딩합니다. 파일이 열리지 않거나 색이 이상하면 끄세요. |
| 페이퍼 화이트 · 하이라이트 압축 | HDR(부동소수점) Spout 화면에만 해당합니다. 흰색이 되는 값과, 그보다 밝은 값을 얼마나 부드럽게 눌러 줄지를 정합니다. |

## DLSS 5 뉴럴 렌더링

결과가 어떻게 보일지 정합니다.

| 설정 | 역할 |
|---|---|
| DLSS 5(DLSSNR) 사용 | DLSS 5를 켜거나 끕니다. 실행 중에는 배지에 **동작 중**이 표시됩니다. 끄면 런타임과 그 비디오 메모리를 해제하고, 켜면 다시 로드합니다. |
| 촬영 시에만 뉴럴 패스 실행 | <sup>고급</sup> 라이브 모드에서, 실시간 미리보기에는 너무 느린 카드를 위한 설정입니다. 미리보기에는 원래 화면이 표시되고 카드는 쉽니다. 사진은 먼저 새 프레임 16개에 DLSS 5를 실행한 다음 저장합니다. 정지 이미지에는 영향이 없습니다. |
| 런타임 경로 · 다시 불러오기 | DLSS 5 런타임 파일입니다. 비워 두면 내 카드에 맞는 내장 빌드를 씁니다. **다시 불러오기**는 런타임을 다시 로드합니다. |
| 프리셋 | 저장해 둔 느낌입니다. **+**는 현재 값을 저장합니다. [프리셋](/ko/presets) |
| 스타일 | **기본**, **내추럴**, **시네마틱**. |
| 강도 | 0~2. 1은 런타임 본래의 느낌이고, 0은 이미지를 그대로 둡니다. 1을 넘으면 앱이 변화를 증폭하며, 결함도 함께 증폭될 수 있습니다. |
| 글로벌 톤 강도 | <sup>고급</sup> DLSS 5가 전체 노출과 색을 얼마나 바꿀 수 있는지 정합니다. 0~2이며, 강도와 마찬가지로 1을 넘으면 앱이 증폭합니다. |
| 로컬 톤 강도 | <sup>고급</sup> 국소 대비와 조명. 범위와 규칙은 같습니다. |
| 로컬 구조 강도 | <sup>고급</sup> 미세한 디테일과 질감. 범위와 규칙은 같습니다. |
| 피부 구조 강도 | <sup>고급</sup> 피부의 디테일. **기본값 사용**이면 모델에 맡깁니다. |
| 자동 마스크 | <sup>고급</sup> 바꾸면 안 되는 영역을 런타임이 마스킹하게 합니다. |
| UI 보정 | <sup>고급</sup> 인터페이스처럼 평평한 영역이 바뀌지 않게 보호합니다. |
| 뉴럴 패스 해상도 | <sup>고급</sup> **전체 화면(100 %)**, **긴 변 최대 1440 px** 같은 상한, **화면의 50 %** 같은 비율 중에서 고릅니다. 패스가 작을수록 카드 부담이 가볍습니다. 그 변화는 원래 크기의 이미지에 더해지며, 가장 미세한 디테일은 사라집니다. |
| 입력 노출(페이퍼 화이트 배율) | <sup>고급</sup> 출력 블렌드. 0.25~4×. 네트워크에 넘기는 이미지만 밝게 하거나 어둡게 하며, 결과는 원래 밝기를 유지합니다. 입력이 밝을수록 조명이 더 부드럽게 다시 입혀집니다. |
| 톤 전달 강도 | <sup>고급</sup> 출력 블렌드. 밝기 변화가 결과에 얼마나 반영될지 정합니다. 0은 원본 유지, 1은 렌더링된 그대로, 2는 과장입니다. |
| 색 강도 | <sup>고급</sup> 출력 블렌드. 색(색상과 채도)에 대해 같은 역할을 합니다. |
| 그림자 강도 | <sup>고급</sup> 출력 블렌드. 어두워지는 변화(그림자와 윤곽)에 대해 같은 역할을 합니다. |
| 하이라이트·글로우 강도 | <sup>고급</sup> 출력 블렌드. 밝아지는 변화(하이라이트, 반사, 글로우)에 대해 같은 역할을 합니다. |
| 시간 이력 초기화 | DLSS 5가 기억하고 있는 이전 프레임의 정보를 지웁니다. |
| 기본값으로 재설정 | DLSS 5 값을 처음 상태로 되돌립니다. |
| GPU 시간 · 처리된 프레임 · 뉴럴 패스 · 출력 변화 | <sup>고급</sup> 측정값입니다. **출력 변화**는 DLSS 5가 이미지를 얼마나 바꿨는지 보여 줍니다. 런타임이 성공을 알렸는데도 검은 이미지나 바뀌지 않은 이미지를 돌려주면 앱이 경고합니다. |

## 프레임 가이던스(모션·깊이)

<sup>고급</sup> 섹션 전체. DLSS 5에 전달하는 모션 정보와, DLAA, 초해상도, 깊이 보기에 쓰이는 깊이를 정합니다. [동작 원리](/ko/how-it-works#inputs)

| 설정 | 역할 |
|---|---|
| 모션 벡터 | **NVIDIA Optical Flow(하드웨어, 권장)**, **FSR 옵티컬 플로우(컴퓨트, 모든 카드)**, **GPU 블록 매칭(내장)**, **없음(0)** 중에서 고릅니다. |
| 플로우 그리드 · 플로우 품질 | NVIDIA Optical Flow: 벡터 간격과 엔진의 속도 설정입니다. 간격이 4 px일 때 가장 빠르고, 2 px 또는 1 px로 하면 더 세밀하지만 4K에서는 훨씬 느립니다. |
| 탐색 반경 | FSR 옵티컬 플로우와 블록 매칭: 얼마나 멀리까지 탐색할지 정합니다. 크게 하면 더 빠른 움직임을 따라가지만 시간이 더 걸립니다. |
| 양방향 일관성 검사 | 모션을 거꾸로도 측정해, 두 방향의 결과가 어긋나는 곳에서는 벡터를 덜 신뢰합니다. 권장합니다. |
| 신뢰도 임계값 | 신뢰도가 이 값보다 낮은 벡터는 약하게 반영됩니다. |
| 깊이 | **AI 추정(Depth Anything V2)**, **평면**, **그라데이션(대체)**, **0** 중에서 고릅니다. DLSS 5는 깊이를 읽지 않습니다. 네트워크는 DLAA, 초해상도, 깊이 보기가 필요로 하는 동안에만 로드됩니다. |
| 깊이 갱신 간격 | N 프레임마다 깊이 네트워크를 실행합니다. 그 사이에는 깊이가 모션을 따라 움직입니다. |
| 깊이 네트워크 해상도 | 깊이 네트워크가 보는 이미지의 긴 변입니다. 크게 하면 가장자리가 더 세밀해지지만 느려집니다. |
| 깊이 모델 | 모델 파일입니다. 비워 두면 내장 모델을 씁니다. |
| 장면 전환 시 자동 초기화 | 화면이 크게 바뀌면 시간 이력을 지웁니다. 처음에는 꺼져 있습니다. DLSS 5는 스스로 회복하며, 초기화할 때마다 화면이 튀어 보이기 때문입니다. |
| 전환 임계값 | 어느 정도의 변화를 장면 전환으로 볼지 정합니다. |

## DLAA 프리패스

<sup>고급</sup> 섹션 전체.

| 설정 | 역할 |
|---|---|
| 뉴럴 렌더링 전에 DLSS DLAA 실행 | DLSS 5 전에 이미지 원래 크기로 실행하는 NVIDIA의 안티에일리어싱입니다. 가장자리를 매끄럽게 하는 대신 GPU 시간이 듭니다. GeForce 전용이며 처음에는 꺼져 있습니다. DLSS 초해상도를 쓰는 동안에는 이 패스가 이미 그 안에 포함됩니다. |
| DLSS 프리셋 | DLSS 모델 문자입니다. 기본값은 **K**입니다. |

| 비교 | **DLSS 5 출력**, **원본**, **와이프(구분선 드래그)**, **모션 벡터**, **깊이** 중에서 고릅니다. |
| 창에 맞춤 · 1:1 픽셀 | 이미지 전체를 창에 맞추거나, 이미지 픽셀 하나를 화면 픽셀 하나로 표시합니다. |

| 투명 영역에 체커보드 | 투명한 부분을 체커보드로 표시합니다. |
| 라이브러리 표시 | 이미지 아래에 라이브러리를 표시합니다. |
| 오버레이 정보 표시 | 크기와 상태를 이미지 위에 표시합니다. |
| 로그 표시 | 앱의 로그를 창 안에 표시합니다. |
| 시작할 때 마지막 파일 다시 열기 | 지난 세션의 파일을 다시 엽니다. 처음에는 꺼져 있습니다. |
| 수직 동기화 | <sup>고급</sup> 화면에 맞춰 창을 그립니다. |
| 처리 속도 상한 | <sup>고급</sup> 라이브 모드: 초당 최대 이 수만큼의 프레임만 처리합니다. 처음에는 **끄기(모든 프레임)**입니다. 카드에 VRChat을 위한 여유를 남겨 줍니다. |
