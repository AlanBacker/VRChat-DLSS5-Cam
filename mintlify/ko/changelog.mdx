## 버전 2.1.0

프로그램 안에서 AI Q&A를 쓸 수 있고, 답변에 나온 컨트롤로 바로 이동할 수 있습니다. v2.0.3이 실행되는 컴퓨터라면 v2.1.0도 그대로 실행됩니다. 프리셋, MCP 도구, 명령줄은 바뀌지 않았고, 설정 파일에는 패널 너비(`askWidth`)만 추가됩니다.

### 새 기능

- AI에게 묻기: 문서의 AI Q&A를 인터페이스 옆에서.
- 답변에서 컨트롤로.
- 질문에 답이 오지 않으면 패널이 이유를 알려 줍니다.
- 온라인, 사용량은 공유.
- 질문하기 전에는 아무것도 전송되지 않습니다.
- WebView2가 없을 때와 Linux에서는.
- 설정 가이드의 마지막 페이지에서 AI Q&A를 소개합니다.
- 서드파티 고지의 중국어, 일본어, 한국어판.

### 개선

- 창 크기 조절이 부드러워졌습니다.
- 줄이 바뀐 사이드바 레이블이 컨트롤과 맞춰집니다.
- 설정 가이드와 *고급*의 도움말이 인터페이스에 적힌 대로 부릅니다.
- 사이드바와 라이브러리의 드래그 선에 더 이상 도움말이 나타나지 않습니다.

[GitHub에서 전체 노트 보기](https://github.com/AlanBacker/VRChat-DLSS5-Cam/releases/tag/v2.1.0)

## 버전 2.0.3

문서 사이트가 생겼고, 프로그램의 *문서* 버튼이 이 사이트를 엽니다. v2.0.2가 실행되는 컴퓨터라면 v2.0.3도 그대로 실행됩니다. 설정 파일, 프리셋, MCP 도구, 명령줄은 바뀌지 않았습니다.

### 새 기능

- 문서 사이트: https://alanbacker.github.io/VRChat-DLSS5-Cam/.
- "정보" 섹션의 *문서* 버튼과 상단 바의 ? 버튼이 사이트를 인터페이스 언어로 엽니다.

[GitHub에서 전체 노트 보기](https://github.com/AlanBacker/VRChat-DLSS5-Cam/releases/tag/v2.0.3)

## 버전 2.0.2

v2.0.1의 문제를 고치고 작은 기능을 더한 정식 릴리스입니다. v2.0.1이 실행되는 컴퓨터라면 v2.0.2도 그대로 실행됩니다. 설정 파일, 프리셋, MCP 도구, 명령줄은 바뀌지 않았으며, 어느 업데이트 채널에서든 프로그램이 이 버전을 알아서 안내합니다.

### 수정

- 깊이 소스를 바꾼 뒤에도 깊이 보기가 다시 표시됩니다.
- 깊이 네트워크는 쓰일 때만 실행됩니다.
- 같은 설정 폴더를 쓰는 두 번째 창이 더 이상 로그를 비우지 않습니다.
- 스크립트 실행이 충돌 알림에 영향을 주지 않습니다.

### 새 기능

- 그래픽 드라이버가 너무 오래됐을 때의 알림.
- 로그가 보관됩니다.
- 충돌 뒤의 알림.
- GitHub 이슈 양식.
- 사용 중인 언어로 보는 릴리스 노트.
