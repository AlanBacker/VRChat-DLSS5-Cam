## 어디서나

| 키 | 동작 |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>P</kbd> | 라이브: VRChat이 앞에 있어도 사진을 저장합니다. 이미지·동영상: 처리하고 저장합니다. **촬영** → **전역 단축키**에서 바꿀 수 있습니다. |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> | 설정이나 라이브러리의 마지막 변경을 되돌립니다. |
| <kbd>Ctrl</kbd>+<kbd>Y</kbd> · <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | 다시 실행합니다. |
| <kbd>F11</kbd> | 이미지를 전체 화면으로 봅니다. <kbd>Esc</kbd>나 <kbd>F11</kbd>을 누르면 빠져나옵니다. |
| <kbd>Tab</kbd> · <kbd>Shift</kbd>+<kbd>Tab</kbd> | 다음 컨트롤이나 이전 컨트롤로 이동합니다. 화살표 키로는 컨트롤 사이를 이동하지 않습니다. |
| 검색 칸에서 <kbd>Esc</kbd> | 검색어를 지웁니다. |
| AI Q&A 패널에서 <kbd>Esc</kbd> | 패널을 닫습니다. [AI Q&A](/ko/ai-qa) |

## 라이브러리

| 이렇게 하면 | 동작 |
|---|---|
| 썸네일 클릭 | 그 파일만 선택합니다. |
| 썸네일 더블클릭 | 미리보기에서 엽니다. |
| <kbd>Ctrl</kbd> + 클릭 | 파일 하나를 선택에 더하거나 뺍니다. |
| <kbd>Shift</kbd> + 클릭 | 마지막으로 클릭한 파일부터 선택을 넓힙니다. |
| 빈 곳에서 드래그 | 선택 상자를 그립니다. 빈 곳을 클릭하면 선택이 풀립니다. |
| 썸네일에서 마우스 오른쪽 버튼 | 파일 메뉴: 개별 매개변수, 탐색기에서 표시, 제거. |
| <kbd>Ctrl</kbd>+<kbd>A</kbd> | 모든 파일을 선택합니다(마우스가 라이브러리 위에 있을 때). |
| <kbd>Delete</kbd> | 선택한 파일을 라이브러리에서 뺍니다. 파일은 디스크에 남습니다. |
