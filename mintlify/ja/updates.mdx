**アップデートが届くまで**

1. **起動時に確認**: GitHub またはミラーサイト
2. **アップデートがあります**: お使いの言語のリリースノート
3. **今すぐ更新**: ダウンロードして展開
4. **再起動**: 設定とライブラリは残る

## 新しいバージョン

アプリは起動するたびに、新しいバージョンがあるかを GitHub に確認します。あれば、そのバージョンと変更内容がお使いの言語でウィンドウに表示されます。

- **今すぐ更新**：新しいバージョンをダウンロードし、アプリを閉じてファイルを置き換え、もう一度起動します。設定、プリセット、ライブラリはそのまま残ります。
- **リリースページ**：ブラウザーでリリースを開きます。
- **あとで**：ウィンドウを閉じます。

## 安定版とプレリリース版

**情報** → **更新チャネル**：

- **安定版**：正式リリースだけを受け取ります。アプリが普通に動けばよいなら、こちらを選んでください。
- **プレリリース版**：正式リリースの前に出るテスト版も受け取ります。新しい機能を早く試せますが、新しい問題に出会うこともあります。

**更新を確認** を押すと、すぐに確認します。**起動時に更新を確認** で自動確認をオフにできます。

## GitHub が遅い・つながらない場合

中国本土をはじめ一部の地域では、GitHub が遅かったり、つながらなかったりします。**情報** → **GitHub へのアクセス** には次の選択肢があります。

- **GitHub に直接接続**：既定の設定です。
- **ミラーサイト（最速を自動選択）**：アプリが既知の 8 つのミラーサイトを測定し、いちばん速いサイトを使います。**サイトを測定** を押すと、各サイトの応答結果が表示されます。
- **自分のミラーサイト**：GitHub を中継する、信頼できるサイトのアドレスを入力します。

どのサイトも応答しないときは、ほかの選択肢を示すウィンドウが開きます。

<Warning>

アプリは更新のときに自分のファイルを置き換えるので、フォルダーに書き込める必要があります。`Program Files` の下のフォルダーは通常書き込めず、その場合はアプリが知らせます。アプリを自分のフォルダーに移すか、リリースページから新しい zip をダウンロードして手動でファイルを置き換えてください。どちらの場合も設定は残ります。

</Warning>
