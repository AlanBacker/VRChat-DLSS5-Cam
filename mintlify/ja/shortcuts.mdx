## どこでも

| キー | 動作 |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>P</kbd> | ライブ：VRChat が前面にあっても写真を保存します。画像・動画：処理して保存します。**撮影** → **グローバルホットキー** で変更できます。 |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> | 設定やライブラリへの直前の変更を元に戻します。 |
| <kbd>Ctrl</kbd>+<kbd>Y</kbd> · <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | やり直します。 |
| <kbd>F11</kbd> | 画像を全画面で表示します。<kbd>Esc</kbd> か <kbd>F11</kbd> で戻ります。 |
| <kbd>Tab</kbd> · <kbd>Shift</kbd>+<kbd>Tab</kbd> | 次または前のコントロールに移動します。矢印キーでコントロール間を移動することはありません。 |
| 検索欄で <kbd>Esc</kbd> | 検索欄を空にします。 |
| AI Q&A のパネルで <kbd>Esc</kbd> | パネルを閉じます。[AI Q&A](/ja/ai-qa) |

## 画像

| マウス | 動作 |
|---|---|
| 画像の上でマウスホイール | ポインターの位置を中心に拡大縮小します。 |
| 画像をドラッグ | 拡大した画像の中を移動します。 |
| ダブルクリック | 画像全体の表示に戻ります。 |
| 白い線をドラッグ | 比較の境界線を動かします（**ワイプ** 表示のとき）。 |
| 切り抜き中に <kbd>Enter</kbd> · <kbd>Esc</kbd> | 切り抜きを適用、または取り消します。 |

## 動画

| キー | 動作 |
|---|---|
| <kbd>Space</kbd> | 再生、または一時停止します。 |
| <kbd>←</kbd> · <kbd>→</kbd> | 1 フレーム戻る、または進みます。<kbd>Shift</kbd> を押しながらなら 10 フレームです。 |
| <kbd>Home</kbd> · <kbd>End</kbd> | 先頭、または末尾に移動します。 |
| <kbd>I</kbd> · <kbd>O</kbd> | 保存する範囲の開始点、または終了点を決めます。 |

## ライブラリ

| 操作 | 動作 |
|---|---|
| サムネイルをクリック | そのファイルだけを選択します。 |
| サムネイルをダブルクリック | プレビューで開きます。 |
| <kbd>Ctrl</kbd> + クリック | ファイルを 1 つ選択に加える、または選択から外します。 |
| <kbd>Shift</kbd> + クリック | 最後にクリックしたファイルから選択を広げます。 |
| 何もない場所をドラッグ | 選択用の枠を描きます。何もない場所をクリックすると選択が解除されます。 |
| サムネイルを右クリック | ファイルのメニューを開きます。個別パラメーター、エクスプローラーで表示、ライブラリから外す、があります。 |
| <kbd>Ctrl</kbd>+<kbd>A</kbd> | すべてのファイルを選択します（マウスがライブラリの上にあるとき）。 |
| <kbd>Delete</kbd> | 選択したファイルをライブラリから外します。ファイルはディスクに残ります。 |

## レイアウト

| 操作 | 動作 |
|---|---|
| サイドバーの横、またはライブラリの上のすき間をクリック | そのパネルを折りたたむ、または広げます。 |
| すき間の端の細い線をドラッグ | サイドバーの幅やライブラリの高さを変えます。どちらもアプリが覚えています。 |
