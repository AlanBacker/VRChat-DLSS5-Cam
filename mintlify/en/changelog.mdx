## Version 2.0.3

A documentation site, and the application's *Documentation* buttons open it. A computer that runs v2.0.2 runs v2.0.3 as it is: the settings file, the presets, the MCP tools and the command line are unchanged.

## Version 2.0.2

Stable release with fixes and small additions over v2.0.1. A computer that runs v2.0.1 runs v2.0.2 as it is: the settings file, the presets, the MCP tools and the command line are unchanged, and a program on either update channel offers this version by itself.

### Fixes

- The depth view comes back after a switch of the depth source.
- The depth network runs only when something uses it.
- A second window on the same settings folder no longer empties the log.
- Scripted runs leave the crash notice alone.

### New

- A notice when the graphics driver is too old.
- Logs are kept.
- A notice after a crash.
- Issue forms on GitHub.
- Release notes in your language.

[Full notes on GitHub](https://github.com/AlanBacker/VRChat-DLSS5-Cam/releases/tag/v2.0.2)
