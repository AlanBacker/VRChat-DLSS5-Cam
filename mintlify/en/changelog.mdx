## Version 2.1.0

AI Q&A inside the application, and answers that point at the controls they name. A computer that runs v2.0.3 runs v2.1.0 as it is: the presets, the MCP tools and the command line are unchanged, and the settings file only gains the panel's width (`askWidth`).

### New

- Ask AI: the documentation's AI Q&A beside the interface.
- From an answer to the control.
- When a question gets no answer, the panel says why.
- Online, with a shared allowance.
- Nothing is sent before you ask.
- Without WebView2, and on Linux.
- The setup guide's last page introduces AI Q&A.
- The third-party notices in Chinese, Japanese and Korean.

### Improvements

- Resizing the window is smooth.
- Sidebar labels that wrap line up with their controls.
- The setup guide and the *Advanced* tip name things as the interface shows them.
- The drag lines of the sidebar and the library no longer show a tooltip.

## Version 2.0.2

Stable release with fixes and small additions over v2.0.1. A computer that runs v2.0.1 runs v2.0.2 as it is: the settings file, the presets, the MCP tools and the command line are unchanged, and a program on either update channel offers this version by itself.
