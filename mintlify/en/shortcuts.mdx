## Everywhere

| Keys | What happens |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>P</kbd> | Live: save a photo, even while VRChat is in front. Picture or video: process and save it. Change it under **Capture** → **Global hotkey**. |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> | Undo the last change to the settings or the library. |
| <kbd>Ctrl</kbd>+<kbd>Y</kbd> · <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | Redo. |
| <kbd>F11</kbd> | Fullscreen picture. <kbd>Esc</kbd> or <kbd>F11</kbd> leaves. |
| <kbd>Tab</kbd> · <kbd>Shift</kbd>+<kbd>Tab</kbd> | Move to the next or the previous control. The arrow keys never move between controls. |
| <kbd>Esc</kbd> in the search field | Clear the search. |

## Picture

| Mouse | What happens |
|---|---|
| Mouse wheel over the picture | Zoom around the pointer. |
| Drag the picture | Move around a zoomed picture. |
| Double-click | Back to the whole picture. |
| Drag the white line | Move the comparison line (in the **Wipe** view). |
| <kbd>Enter</kbd> · <kbd>Esc</kbd> while cropping | Apply the crop, or cancel it. |

## Video

| Keys | What happens |
|---|---|
| <kbd>Space</kbd> | Play or pause. |
| <kbd>←</kbd> · <kbd>→</kbd> | One frame back or forward. With <kbd>Shift</kbd>: ten frames. |
| <kbd>Home</kbd> · <kbd>End</kbd> | Jump to the start or the end. |
| <kbd>I</kbd> · <kbd>O</kbd> | Set the start or the end of the part to save. |

## Library

| Do this | What happens |
|---|---|
| Click a thumbnail | Select only that file. |
| Double-click a thumbnail | Open it in the preview. |
| <kbd>Ctrl</kbd> + click | Add one file to the selection, or take it out. |
| <kbd>Shift</kbd> + click | Extend the selection from the last click. |
| Drag over empty space | Draw a selection box. A click on empty space clears the selection. |
| Right button on a thumbnail | The file's menu: own parameters, show in Explorer, remove. |
| <kbd>Ctrl</kbd>+<kbd>A</kbd> | Select every file (with the mouse over the library). |
| <kbd>Delete</kbd> | Take the selected files out of the library. The files stay on disk. |

## Layout

| Do this | What happens |
|---|---|
| Click the gap beside the sidebar, or above the library | Fold or unfold that panel. |
| Drag the thin line at the gap's edge | Change the sidebar's width or the library's height. The app remembers both. |
