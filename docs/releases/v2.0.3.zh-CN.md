新增文档网站，程序中的*文档*按钮都会打开它。能运行 v2.0.2 的电脑可以直接运行 v2.0.3：设置文件、预设、MCP 工具和命令行都没有变化。

## 新增

- **文档网站：https://alanbacker.github.io/VRChat-DLSS5-Cam/** 提供英语、简体中文、日语和韩语四种语言。它从 README 不好读懂的部分讲起：从下载到保存第一张图片，一步一步讲解，配有截图和简单的示意图；然后是来自 VRChat 的实时画面、视频与素材库、预设、输出和更新。参考部分按侧边栏的分组列出全部设置，并介绍命令行、MCP、Linux 软件包、Radeon 版和常见问题。和程序一样，网站跟随系统使用浅色或深色主题，不启用 JavaScript 也能正常浏览。网站由本仓库的 `tools/site/` 生成到 `site/`，通过 GitHub Pages 发布；各 README 仍是完整的参考资料，并在开头指向网站。
- **“关于”分节中的*文档*按钮和顶栏的 ? 按钮会以界面语言打开网站**；MCP 分节中的*文档*按钮会打开网站的 MCP 页面。以前它们打开的是 GitHub 上的 README。
