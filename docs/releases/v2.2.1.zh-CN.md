Radeon 版重新可以安装 DLSS-NR-on-AMD，程序新增了来自本仓库的公告通道。能运行 v2.2.0 的电脑可以直接运行 v2.2.1：预设、MCP 工具和命令行都没有变化，设置文件只多了已关闭公告的记录（`noticesDismissed`）。

## 修正

- **DLSS-NR-on-AMD 无法安装。** 自 10 月 17 日起，DLSS-NR-on-AMD 的发布改为 NeuralHub，安装器和磁盘上的布局都不同；Radeon 版查询的是最新发布，在其中找不到 `dlssnr_on_amd_setup.exe`：启动时的检查以 *the latest release carries no dlssnr_on_amd_setup.exe* 失败，安装按钮也装不上（GitHub issue #7）。程序现在只适配一个指定的发布 **v0.2.17**，也就是最后一个经过测试的版本：查询时只查它，安装按钮获取的是它，DLSS 5 分节把它和已安装的版本并列显示，已安装的更旧或更新时都会说明。用更早版本完成的安装照常可用。对 NeuralHub 的支持会在后续版本中跟进。

## 新增

- **来自仓库的公告。** 启动时，程序沿着和更新检查相同的路径（直连 GitHub 或所选镜像站）读取本仓库的 `notice.json`，把适用于当前版本和当前显卡版本的公告以卡片形式显示在侧栏顶部和*开始使用*页，带有*详情*和*知道了*两个按钮。关闭过的公告不再出现。这条通道用于等不到下个版本的消息，例如 DLSS-NR-on-AMD 的变动。Radeon 版要安装的发布也以同样方式从 `port.json` 读取，因此在仓库里改动即可，不必发新版本。
