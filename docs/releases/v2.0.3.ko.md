문서 사이트가 생겼고, 프로그램의 *문서* 버튼이 이 사이트를 엽니다. v2.0.2가 실행되는 컴퓨터라면 v2.0.3도 그대로 실행됩니다. 설정 파일, 프리셋, MCP 도구, 명령줄은 바뀌지 않았습니다.

## 새 기능

- **문서 사이트: https://alanbacker.github.io/VRChat-DLSS5-Cam/** 영어, 중국어 간체, 일본어, 한국어로 제공됩니다. README로는 읽기 어려웠던 부분부터 시작합니다. 다운로드부터 첫 이미지를 저장하기까지 스크린샷과 간단한 도식을 곁들여 한 단계씩 설명하고, 이어서 VRChat에서 들어오는 라이브 화면, 동영상과 라이브러리, 프리셋, 출력, 업데이트를 다룹니다. 레퍼런스 부분에는 사이드바와 같은 묶음으로 정리한 모든 설정, 명령줄, MCP, Linux 패키지, Radeon 에디션, 문제 해결이 있습니다. 프로그램과 마찬가지로 시스템의 라이트·다크 테마를 따르며, JavaScript 없이도 볼 수 있습니다. 사이트는 이 저장소의 `tools/site/`에서 `site/`로 생성되어 GitHub Pages로 게시되며, README는 계속 전체 레퍼런스 역할을 하고 맨 위에서 사이트를 안내합니다.
- **"정보" 섹션의 *문서* 버튼과 상단 바의 ? 버튼이 사이트를 인터페이스 언어로 엽니다**. MCP 섹션의 *문서* 버튼은 사이트의 MCP 페이지를 엽니다. 예전에는 모두 GitHub의 README를 열었습니다.
