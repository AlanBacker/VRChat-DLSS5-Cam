v2.0.1 の不具合を修正し、小さな機能を加えた正式リリースです。v2.0.1 が動くコンピューターなら、v2.0.2 もそのまま動きます。設定ファイル、プリセット、MCP ツール、コマンドラインに変更はなく、どちらの更新チャネルでもプログラムがこのバージョンを自動で案内します。

## 修正

- **深度ソースを切り替えたあとも、深度表示が元に戻ります。** 深度表示を開いたまま、深度ソースを推定器から*フラット*や*ゼロ*に切り替えて戻すと、アプリを再起動するまで表示が黒いままでした。静止画の 2 回の再処理を推定器の最初の起動で使い切っていたため、推定器が再び起動したあとに届いた推定結果が表示されなかったのです。再処理は推定器の起動ごとに数えるようになり、深度表示がオフの間に停止していた推定器は、深度表示をオンに戻すと再び起動します。
- **深度ネットワークは、使われるときだけ動きます。** DLSS 5 自体が受け取るのは画像とモーションベクトルだけです（NVIDIA の説明どおりで、こちらでも確認しました。RTX 5090 では、フラット、グラデーション、ゼロのどの深度でもニューラルパスの出力はバイト単位で同一です）。そのため深度ネットワーク（約 400 MB のメモリと DirectML のウォームアップが必要）は、DLSS 機能が深度を受け取る DLAA と超解像、そして深度表示のためだけに読み込み、それらがすべてオフになると停止します。DLSS 5 だけで静止画を保存するときは、深度ネットワークを待たなくなりました。*深度*のヒントと深度推定の状態表示で、どのパスが深度を使うかがわかります。深度を使うパスがない間、オーバーレイの深度の行は*未使用*と表示されます（以前は*ゼロ*と表示されていましたが、これはかつて不具合を意味する表示でした）。
- **同じ設定フォルダーで 2 つ目のウィンドウを開いても、ログが消えなくなりました。** 別のプロセスが開いたままの `log.txt` は、起動時に名前を変更できません。この場合はログを空にせず続きから書き込むようになったため、前のセッションの記録が残ります。
- **スクリプト実行がクラッシュ通知に影響しなくなりました。** スクリプトで終了する実行（`--process`、`--exit-after`、`--headless`）はセッションマーカーを書かず、通知も表示しません。見つけたマーカーはそのまま残し、次にウィンドウで起動したセッションが正しいログとともに知らせます。また、プロセス ID は再利用されるため、クラッシュしたプロセスと同じ ID がたまたま割り当てられただけのプロセス（このプログラム自身を含む）を、そのプロセスと取り違えることはなくなりました。

## 新機能

- **グラフィックドライバーが古いときの通知。** 同梱の DLSS 5 ランタイムには GeForce ドライバー 616.56 以降が必要で、それより古いドライバーではニューラルパスが起動しません。プログラムは起動のたびにドライバーを確認し、古い場合はグラフィックカード名、インストール済みのバージョンと必要なバージョン、NVIDIA のダウンロードページを載せた通知を表示します（**ドライバーをダウンロード** でページを開いても通知は閉じないので、探すバージョンを見ながら操作できます）。*今後表示しない*で通知を止め、*情報*の*起動時にドライバーを確認*で再び有効にできます。ドライバーを更新するまで、DLSS 5 セクションには警告行が残ります。プログラムのほかの機能は古いドライバーでも動作し、コマンドラインからのバッチ処理ではログに警告を書くだけです。
- **ログが残るようになりました。** 起動時に `log.txt` が空にされなくなりました。以前のセッションのログは `log-1.txt`〜`log-5.txt` としてその隣に残ります。
- **クラッシュ後の通知。** 前回のセッションが正常に終了しなかった場合（クラッシュ、強制終了、停電）、次の起動時にそのログを `log-crash.txt` として残し、ダイアログで知らせます。ボタンは **GitHub で報告**（バージョン、エディション、グラフィックカード、ドライバー、システムを入力済みの Issue フォームを開きます。クラッシュの記録があればそれも添えます）、**ログフォルダを開く**、**閉じる** の 3 つです。「情報」セクションにも同じ **問題を報告** ボタンがあります。スクリプト実行ではダイアログを表示しません。
- **GitHub の Issue フォーム**を英語、中国語、日本語、韓国語で用意しました。不具合の報告と機能の提案の 2 種類で、4 つの README へのリンクがあります。フォームで尋ねるバージョンは*情報*の一番上に表示されています。
- **お使いの言語のリリースノート。** 更新ウィンドウは、リリースノートをインターフェースの言語（英語、簡体字中国語、日本語、韓国語）で表示します。訳文のないリリースでは英語の原文を表示します。
