ドキュメントサイトを公開し、アプリの*ドキュメント*ボタンでこのサイトが開くようになりました。v2.0.2 が動くコンピューターなら、v2.0.3 もそのまま動きます。設定ファイル、プリセット、MCP ツール、コマンドラインに変更はありません。

## 新機能

- **ドキュメントサイト：https://alanbacker.github.io/VRChat-DLSS5-Cam/** 英語、簡体字中国語、日本語、韓国語で読めます。README では読みにくかったところから始まり、ダウンロードから最初の画像を保存するまでを、スクリーンショットと小さな図を添えて一歩ずつ説明します。続いて VRChat からのライブ映像、動画とライブラリ、プリセット、出力、アップデートを扱います。リファレンスの部分には、サイドバーと同じまとまりで並べたすべての設定、コマンドライン、MCP、Linux パッケージ、Radeon 版、トラブルシューティングがあります。アプリと同じくシステムのライト／ダークテーマに従い、JavaScript なしでも表示できます。サイトはこのリポジトリの `tools/site/` から `site/` に生成し、GitHub Pages で公開しています。README は引き続き完全なリファレンスで、冒頭でサイトを案内しています。
- **「情報」セクションの*ドキュメント*ボタンとトップバーの ? ボタンは、サイトをインターフェースの言語で開きます**。MCP セクションの*ドキュメント*ボタンは、サイトの MCP ページを開きます。以前はいずれも GitHub の README を開いていました。
