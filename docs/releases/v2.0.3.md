## New

- **A documentation site: https://alanbacker.github.io/VRChat-DLSS5-Cam/** in English, Simplified Chinese, Japanese and Korean. It begins where the README was hard to read: from the download to the first saved picture, step by step, with screenshots and small diagrams; then the live path from VRChat, videos and the library, presets, outputs and updates. The reference part has every setting as the sidebar groups them, the command line, MCP, the Linux package, the Radeon edition and troubleshooting. Like the application, the site follows the system's light or dark theme, and it works without JavaScript. It is built from `tools/site/` into `site/` in this repository and published by GitHub Pages; the READMEs stay the full reference and point to the site at the top.
- **The *Documentation* button in About and the ? button in the top bar open the site in the interface's language**; the *Documentation* button in the MCP section opens the site's MCP page. They opened the README on GitHub before.
