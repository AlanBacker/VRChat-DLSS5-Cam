## どこでも {#general}

| キー | 動作 |
|---|---|
| ((Ctrl+Alt+P)) {#hotkey} | ライブ：VRChat が前面にあっても写真を保存します。画像・動画：処理して保存します。**撮影** → **グローバルホットキー** で変更できます。 |
| ((Ctrl+Z)) {#undo} | 設定やライブラリへの直前の変更を元に戻します。 |
| ((Ctrl+Y)) · ((Ctrl+Shift+Z)) {#redo} | やり直します。 |
| ((F11)) {#fullscreen} | 画像を全画面で表示します。((Esc)) か ((F11)) で戻ります。 |
| ((Tab)) · ((Shift+Tab)) {#tab} | 次または前のコントロールに移動します。矢印キーでコントロール間を移動することはありません。 |
| 検索欄で ((Esc)) {#search} | 検索欄を空にします。 |

## 画像 {#picture}

| マウス | 動作 |
|---|---|
| 画像の上でマウスホイール {#wheel} | ポインターの位置を中心に拡大縮小します。 |
| 画像をドラッグ {#drag} | 拡大した画像の中を移動します。 |
| ダブルクリック {#double-click} | 画像全体の表示に戻ります。 |
| 白い線をドラッグ {#wipe} | 比較の境界線を動かします（**ワイプ** 表示のとき）。 |
| 切り抜き中に ((Enter)) · ((Esc)) {#crop} | 切り抜きを適用、または取り消します。 |

## 動画 {#video}

| キー | 動作 |
|---|---|
| ((Space)) {#play} | 再生、または一時停止します。 |
| ((←)) · ((→)) {#step} | 1 フレーム戻る、または進みます。((Shift)) を押しながらなら 10 フレームです。 |
| ((Home)) · ((End)) {#ends} | 先頭、または末尾に移動します。 |
| ((I)) · ((O)) {#range} | 保存する範囲の開始点、または終了点を決めます。 |

## ライブラリ {#library}

| 操作 | 動作 |
|---|---|
| サムネイルをクリック {#click} | そのファイルだけを選択します。 |
| サムネイルをダブルクリック {#open} | プレビューで開きます。 |
| ((Ctrl)) + クリック {#ctrl-click} | ファイルを 1 つ選択に加える、または選択から外します。 |
| ((Shift)) + クリック {#shift-click} | 最後にクリックしたファイルから選択を広げます。 |
| 何もない場所をドラッグ {#marquee} | 選択用の枠を描きます。何もない場所をクリックすると選択が解除されます。 |
| サムネイルを右クリック {#menu} | ファイルのメニューを開きます。個別パラメーター、エクスプローラーで表示、ライブラリから外す、があります。 |
| ((Ctrl+A)) {#select-all} | すべてのファイルを選択します（マウスがライブラリの上にあるとき）。 |
| ((Delete)) {#delete} | 選択したファイルをライブラリから外します。ファイルはディスクに残ります。 |

## レイアウト {#layout}

| 操作 | 動作 |
|---|---|
| サイドバーの横、またはライブラリの上のすき間をクリック {#fold} | そのパネルを折りたたむ、または広げます。 |
| すき間の端の細い線をドラッグ {#resize} | サイドバーの幅やライブラリの高さを変えます。どちらもアプリが覚えています。 |
