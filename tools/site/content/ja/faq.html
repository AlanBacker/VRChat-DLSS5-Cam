無料ですか？

はい。アプリは無料のオープンソースで、MIT ライセンスで公開しています。

VRChat でアカウント停止（BAN）の対象になりますか？

アプリは VRChat に一切手を加えません。Mod も要らず、VRChat のプロセスを開くこともありません。受け取るのは、VRChat 自身のカメラが Spout を通して送る映像だけです。Spout は、VRChat が配信向けに用意している機能です。

画像はアップロードされますか？

いいえ。すべての処理はお使いのグラフィックカード上で行われます。アプリがネットに接続するのは、更新を探すときと、Radeon 版で求めに応じて DLSS-NR-on-AMD を取得するときだけです。プライバシーとライセンス

VRChat がなくても使えますか？

はい。ディスク上の画像や動画なら VRChat は要りません。VRChat が必要なのはライブカメラだけです。

どのグラフィックカードで使えますか？

NVIDIA GeForce RTX 20、30、40、50 は GeForce 版で、AMD Radeon RX 7000 と 9000 は Radeon 版 で使えます。それ以外のカードでは、アプリは DLSS 5 なしのビューアーと録画ツールとして動きます。

DLSS 5 ランタイムをダウンロードする必要はありますか？

いいえ。GeForce 版にはランタイムが入っていて、RTX 50 向けと RTX 40 / 30 / 20 向けの 2 つのビルドがあります。合うほうをアプリが選びます。

起動すると Windows が警告するのはなぜですか？

アプリが有料の証明書で署名されていないためです。詳細情報 をクリックし、実行 を押してください。ソースコードは公開されていて、すべてのリリースはそのソースコードから GitHub 上でビルドされています。

DLSS 5 で顔や肌が変わるのはなぜですか？

DLSS 5 は光と素材を描き直します。肌も素材の 1 つです。強度 を下げるか、詳細 をオンにして スキン構造強度 と ローカル構造強度 を下げてください。気に入った見た目をプリセットとして保存しておくと、次から便利です。プリセット

保存した画像はどこにありますか？

撮影 → 保存先 で別のフォルダーを選んでいなければ、Pictures\VRChat DLSS5 Cam にあります。ステータスバーに最後に保存したファイルの名前が表示され、隣のボタンでエクスプローラーに表示できます。保存先

1 枚の画像が動画の 1 フレームより遅いのはなぜですか？

静止画には前のフレームがないため、アプリは結果が落ち着くまで何回か DLSS 5 に通します。仕組み

ノート PC でも使えますか？

GeForce RTX カードを搭載していれば使えます。DLSS 5 はカードにとって重い処理なので、電源につないで使ってください。

Linux や Mac で使えますか？

NVIDIA カードを積んだ Linux なら、Proton を通して画像と動画に使えます。Linux Mac 版はありません。

ライブ映像をもっと鮮明にするには？

VRChat のカメラの設定で、ストリームのサイズを最大 2160p まで上げてください。VRChat からライブ

問題の報告や機能の要望はどこでできますか？

GitHub で受け付けています。情報 → 問題を報告 でフォームが開きます。完成した画像は、X で #VRCDLSS5CAM を付けて投稿していただけるとうれしいです。
