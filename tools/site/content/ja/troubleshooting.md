## ライブカメラ {#live}

### 「Spout 送信元が見つかりません」 {#no-sender}

映像を送っているプログラムがありません。VRChat で **カメラ** を開き、**Stream** モードに切り替えて **Spout Stream** をオンにしてください。カメラは開いたままにしておく必要があります。

### 「VRChat の Spout ストリームを待機中…」 {#waiting}

送信元は動いていますが、選んでいる送信元からまだ映像が届いていません。VRChat のカメラが開いているか確認するか、**ソース** → **Spout 送信元** で別の送信元を選んでください。

## DLSS 5 {#dlss5}

### 「グラフィックドライバーの更新が必要です」 {#driver}

DLSS 5 には GeForce ドライバー 616.56 以降が必要です。通知の **ドライバーをダウンロード** をクリックし、最新のドライバーをインストールしてから、アプリを起動し直してください。[グラフィックドライバー](install.html#driver)

### 「ランタイムのファイルがありません」 {#runtime-missing}

zip が最後まで展開されていません。**すべて展開** を使って、新しいフォルダーにもう一度展開してください。`runtimes\blackwell\nvngx_dlssnr.dll` と `runtimes\universal\nvngx_dlssnr.dll` のファイルが、`VRChatDLSS5Cam.exe` と同じ場所にあるはずです。

### DLSS 5 が起動しない {#failed}

アプリはもう一方の同梱ビルドを自動で試し、そのことを知らせます。どちらも起動しない場合は、次の手順を試してください。

1. 最新のグラフィックドライバーをインストールします。
2. アプリを起動し直します。
3. それでも失敗する場合は、**情報** → **問題を報告** から、`log.txt` を添えて報告してください。

### 動作中なのに画像が黒い、または変わらない {#unchanged}

アプリは DLSS 5 のフレームを毎回入力と比べ、ランタイムが黒い画像や変化のない画像を返すと警告します。**DLSS 5（DLSSNR）を有効化** を一度オフにして、もう一度オンにしてください。**強度** が 0 のときは画像が変わらないのが正常で、警告も出ません。

## 速度 {#slow}

### ライブ映像が重い {#live-slow}

次のことを 1 つずつ試してください。

1. **DLAA プリパス** と **DLSS 超解像** をオンにしている場合は、オフにします。
2. **ニューラルパス解像度** を小さくします。たとえば **長辺 1440 px まで** を選びます。
3. **処理レート上限** を設定します。
4. **撮影時のみニューラルパスを実行** をオンにします。プレビューは休みますが、写真には DLSS 5 がかかります。

これらのコントロールは、**詳細** がオンのときに表示されます。**フローグリッド** は 4 px のままにしてください。2 px と 1 px は、4K では負担がずっと大きくなります。

### 「グラフィックデバイスが失われました」 {#device-lost}

グラフィックドライバーがカードをリセットしました。Windows は 1 つの処理につき約 2 秒をカードに与えますが、長い間フル稼働しているカードは、それに間に合わないことがあります。たとえば、VRChat と DLSS 5 が同じカードで大きなサイズで動いているときです。アプリは自動で再起動し、そのことを知らせます。

繰り返し起きる場合は、負担を減らしてください。処理レート上限、ニューラルパス解像度を小さくする、出力サイズを小さくする、VRChat でフレームレートを制限する、といった方法があります。新しいグラフィックドライバーを試す価値もあります。

## 動画 {#videos}

### 動画のプレビューが黒い {#video-black}

多くの動画は、黒からのフェードで始まります。プレビューはそうしたフレームを飛ばし、画像の下でそのことを知らせます。シークバーか矢印キーで先に進んでください。

### 動画が開けない、または MP4 で保存できない {#video-codecs}

どの形式が使えるかは Windows が決めます。HEVC ファイルには Microsoft Store の **HEVC ビデオ拡張機能** が、Windows の N エディションには **Media Feature Pack** が必要です。グラフィックカードが受け付けないファイルは、**ソース** → **ハードウェアデコード** をオフにすると開けることがあります。出力形式を **PNG 連番** にすれば、必ず保存できます。

## アップデート {#updates}

### アップデートをインストールできない {#update-folder}

アプリのフォルダーには書き込める必要がありますが、`Program Files` の下のフォルダーは通常書き込めません。アプリを自分のフォルダーに移すか、リリースページから新しい zip をダウンロードして、手動でファイルを置き換えてください。設定とライブラリは残ります。

### 更新の確認に失敗する {#update-check}

GitHub が遅い、またはつながらない場合は、**情報** → **GitHub へのアクセス** → **ミラーサイト（最速を自動選択）** を選んでください。[アップデート](updates.html#mirror)

## アプリが閉じた・クラッシュした {#crash}

次に起動したとき、アプリは前回のセッションが正常に終了しなかったことに気づきます。ウィンドウが開き、記入済みの Issue フォームを開く **GitHub で報告** と、**ログフォルダを開く** が表示されます。

ログフォルダーは `%LOCALAPPDATA%\VRChatDLSS5Cam` です。報告には `log-crash.txt` と `crash.txt` を添えてください。**情報** → **問題を報告** もいつでも使えます。

> [!TIP]
> 報告する前に、報告フォームに一度目を通してください。アプリのバージョンとお使いのグラフィックカードが記入されています。送信するまで、何も送られることはありません。
