サイドバーのセクションは、上から順に **ソース**、**DLSS 5 ニューラルレンダリング**、**撮影**、**フレームガイダンス（モーション・深度）**、**DLAA プリパス**、**表示**、**MCP**、**内部情報**、**情報** です。セクションのタイトルをクリックすると折りたためます。

{adv} の付いたコントロールは、サイドバー上部の **詳細** スイッチがオンのときだけ表示されます。最初はオンです。オフにすると、最初の 1 枚に必要なものだけが残ります。

> [!TIP]
> **詳細** スイッチの隣の検索欄では、どのコントロールでも名前で探せます。**詳細** がオフで隠れているものも見つかります。((Esc)) で検索欄を空にします。

## ソース {#source}

何を受け取り、どのサイズと形式で出力するかを決めます。

![](sidebar-source "画像を開いているときの「ソース」セクション。")

| 設定 | 役割 |
|---|---|
| Spout 送信元 {#spout-sender} | ライブモード：どこから映像を受け取るか。**自動（VRChat）** は VRChat のカメラを見つけます。**更新** で送信元を探し直します。 |
| 画像を開く… · 動画を開く… {#open-file} | 画像モードと動画モード：ファイルを開きます。隣の ✕ でファイルを閉じます。ファイルはライブラリに残ります。 |
| 出力解像度をカスタム指定 {#custom-resolution} | 元とは違うサイズで保存します。**幅** と **高さ** を設定し、**アスペクト比を維持** で縦横の比率を保ちます。元より大きければアップスケール、小さければダウンスケールです。 |
| アップスケール方式 {#upscaling} | 画像の拡大方法です。**DLSS 超解像**：NVIDIA のアップスケーラーが細部を作り直し、そのあと DLSS 5 が大きな画像を処理します。かなり遅くなり、VRAM も多く必要です。**リサンプリング（Catmull-Rom）**：単純なフィルターです。 |
| 元動画の仕様に合わせる {#match-source} | 動画用。最初はオンで、結果は元の動画の形式、フレームレート、ビットレートを引き継ぎます。アニメーション GIF、APNG、WebP は、それぞれ元の形式のまま、ループ回数も保って保存されます。 |
| 保存形式 {#save-as} | **元動画の仕様に合わせる** がオフのとき：**MP4 (H.264)**、**MP4 (HEVC)**、**PNG 連番**、**GIF**、**APNG**、**WebP** から選びます。[どれを選ぶか](videos.html#format) |
| ビットレート {#bitrate} | MP4：平均ビットレート。5〜200 Mbit/s です。40 なら 4K でも圧縮ノイズはほとんど目立ちません。 |
| 音声を保持 {#keep-audio} | MP4：音声を結果にコピーします。 |
| WebP 品質 {#webp-quality} | アニメーション WebP：50〜100。高いほど画質がよく、ファイルも大きくなります。100 はロスレスです。 |
| ハードウェアデコード {#hardware-decoding} | {adv} グラフィックカードで動画をデコードします。ファイルが開けない、または色がおかしい場合はオフにしてください。 |
| ペーパーホワイト · ハイライト圧縮 {#hdr} | HDR（浮動小数点）の Spout 映像のときだけ：白になる値と、それより明るい値をどれだけなだらかに抑えるかです。 |

## DLSS 5 ニューラルレンダリング {#dlss5}

結果の見た目を決めます。

![](sidebar-dlss5 "「詳細」がオンのときの「DLSS 5 ニューラルレンダリング」セクション。")

| 設定 | 役割 |
|---|---|
| DLSS 5（DLSSNR）を有効化 {#enable} | DLSS 5 のオン・オフを切り替えます。動いている間、バッジに **動作中** と表示されます。オフにするとランタイムとその VRAM を解放し、オンにすると読み込み直します。 |
| 撮影時のみニューラルパスを実行 {#capture-only} | {adv} ライブモード用。ライブプレビューには遅すぎるカード向けです。プレビューには元の映像が表示され、カードは休みます。写真はまず新しい 16 フレームで DLSS 5 を実行してから保存します。静止画には影響しません。 |
| ランタイムのパス · 再読み込み {#runtime} | DLSS 5 のランタイムファイルです。空なら、お使いのカード向けに同梱されたビルドを使います。**再読み込み** で読み込み直します。 |
| プリセット {#preset} | 保存した見た目です。**+** で現在の値を保存します。[プリセット](presets.html) |
| スタイル {#style} | **既定**、**ナチュラル**、**シネマティック** から選びます。 |
| 強度 {#intensity} | 0〜2。1 はランタイム本来の見た目、0 は画像をそのまま残します。1 を超えるとアプリが変化を増幅し、粗も増幅されることがあります。 |
| グローバルトーン強度 {#global-tone} | {adv} DLSS 5 が全体の露出と色をどれだけ変えてよいか。0〜2 で、1 を超えると **強度** と同じくアプリが増幅します。 |
| ローカルトーン強度 {#local-tone} | {adv} 局所的なコントラストと光。範囲と決まりは同じです。 |
| ローカル構造強度 {#local-structure} | {adv} 細部と質感。範囲と決まりは同じです。 |
| スキン構造強度 {#skin-structure} | {adv} 肌の細部。**既定値を使用** ではモデルに任せます。 |
| 自動マスク {#auto-mask} | {adv} 変えるべきでない領域を、ランタイムにマスクさせます。 |
| UI 補正 {#ui-correction} | {adv} インターフェースのような平坦な領域が変わらないように守ります。 |
| ニューラルパス解像度 {#pass-resolution} | {adv} **完全な画像（100 %）**、**長辺 1440 px まで** のような上限、**画像の 50 %** のような割合から選びます。パスを小さくするとカードの負担は減ります。その変化はフルサイズの画像に加えられ、いちばん細かい部分は失われます。 |
| 入力露出（ペーパーホワイト倍率） {#input-exposure} | {adv} 出力ブレンド。0.25〜4 倍。ネットワークに渡す画像だけを明るく、または暗くします。結果は元の明るさを保ちます。入力が明るいほど、光の描き直しは穏やかになります。 |
| トーン転送強度 {#tone-transfer} | {adv} 出力ブレンド。明るさの変化をどれだけ結果に反映するか。0 で元のまま、1 で描画どおり、2 で誇張します。 |
| 色の強度 {#colour-strength} | {adv} 出力ブレンド。色（色相と彩度）について同じことをします。 |
| シャドウ強度 {#shadow-strength} | {adv} 出力ブレンド。暗くする変化（影と輪郭）について同じことをします。 |
| ハイライトとグロー強度 {#highlight-strength} | {adv} 出力ブレンド。明るくする変化（ハイライト、反射、グロー）について同じことをします。 |
| 時間履歴をリセット {#reset-history} | DLSS 5 が覚えている過去のフレームの情報を消します。 |
| 既定値に戻す {#reset-defaults} | DLSS 5 の値を最初の状態に戻します。 |
| GPU 時間 · 処理済みフレーム · ニューラルパス · 出力の変化 {#readouts} | {adv} 計測値の表示です。**出力の変化** は DLSS 5 が画像をどれだけ変えたかを示します。ランタイムが成功を報告したのに黒い画像や変化のない画像が返ってきた場合は、アプリが警告します。 |

## 撮影 {#capture}

結果の保存先と名前の付け方を決めます。

![](sidebar-output "画像モードの「撮影」セクション。")

| 設定 | 役割 |
|---|---|
| 撮影 · 処理して PNG を保存 · 処理して動画を保存 {#save-button} | 保存します。ボタンの名前はモードによって変わります。 |
| 推定処理時間 {#estimated-time} | 画像と動画：このカードで保存にかかるおおよその時間です。処理するたびに正確になります。 |
| 保存先 {#folder} | すべての保存先です。空なら `Pictures\VRChat DLSS5 Cam` です。**参照…** でフォルダーを選び、**開く** で表示します。 |
| ファイル名 · 出力ファイル名 {#file-name} | 名前のテンプレートです。前者はライブの写真用、後者は画像と動画用です。[使える言葉](saving.html#names) |
| 元のフレームも保存 {#save-original} | DLSS 5 をかける前の、届いたままの画像も保存します。 |
| 透明度（アルファ）を保持 {#keep-alpha} | {adv} 透明な背景を残します。最初はオンです。 |
| グローバルホットキー {#hotkey} | ライブモード：VRChat が前面にあるときに写真を保存するキーです。最初は ((Ctrl+Alt+P)) です。**Ctrl**、**Alt**、**Shift**、**Win** にチェックを入れ、**キー** を選びます。 |
| 自動撮影の間隔（秒） {#timelapse} | ライブモード：この間隔で写真を保存します。**0 = オフ** です。 |

## フレームガイダンス（モーション・深度） {#guidance}

{adv} セクション全体。DLSS 5 に伝える動きの情報と、DLAA、超解像、深度表示が使う深度を決めます。[仕組み](how-it-works.html#inputs)

![](sidebar-depth-motion "「フレームガイダンス」セクション。")

| 設定 | 役割 |
|---|---|
| モーションベクトル {#motion-vectors} | **NVIDIA Optical Flow（ハードウェア・推奨）**、**FSR オプティカルフロー（コンピュート・全カード）**、**GPU ブロックマッチング（内蔵）**、**なし（ゼロ）** から選びます。 |
| フローグリッド · フロー品質 {#flow-grid} | NVIDIA Optical Flow：ベクトルの間隔と、エンジンの速度設定です。4 px がいちばん速く、2 px と 1 px は細かいものの 4K ではかなり遅くなります。 |
| 探索半径 {#search-radius} | FSR オプティカルフローとブロックマッチング：どこまで探すか。大きいほど速い動きを追えますが、時間がかかります。 |
| 双方向一貫性チェック {#bidirectional} | 逆方向の動きも測り、2 つの方向が食い違う場所ではベクトルを信用しすぎないようにします。おすすめです。 |
| 信頼度しきい値 {#confidence} | 信頼度がこの値より低いベクトルは弱められます。 |
| 深度 {#depth} | **AI 推定（Depth Anything V2）**、**フラット**、**グラデーション（代替）**、**ゼロ** から選びます。DLSS 5 は深度を読みません。ネットワークが読み込まれるのは、DLAA、超解像、深度表示が必要とするときだけです。 |
| 深度更新間隔 {#depth-interval} | 深度ネットワークを N フレームごとに実行します。その間の深度は動きに合わせて追従します。 |
| 深度ネットワーク解像度 {#depth-resolution} | 深度ネットワークに渡す画像の長辺です。大きいほど輪郭が細かくなり、遅くなります。 |
| 深度モデル {#depth-model} | モデルファイルです。空なら同梱のものを使います。 |
| シーン切替時に自動リセット {#auto-reset} | 画像が大きく変わったときに時間履歴を消します。最初はオフです。DLSS 5 は自分で回復し、リセットのたびに映像が飛んで見えるためです。 |
| 切替しきい値 {#cut-threshold} | どれだけの変化をシーンの切り替わりとみなすかです。 |

## DLAA プリパス {#dlaa}

{adv} セクション全体。

| 設定 | 役割 |
|---|---|
| ニューラルレンダリングの前に DLSS DLAA を実行 {#dlaa-enable} | DLSS 5 の前に、画像本来のサイズで NVIDIA のアンチエイリアスをかけます。輪郭がなめらかになり、そのぶん GPU 時間がかかります。GeForce 専用で、最初はオフです。DLSS 超解像を使っている間は、このパスはすでに超解像に含まれています。 |
| DLSS プリセット {#dlaa-preset} | DLSS モデルの文字です。既定は **K** です。 |

## 表示 {#display}

ウィンドウでの見せ方を決めます。どれも保存されるファイルには影響しません。

![](sidebar-display "「表示」セクション。")

| 設定 | 役割 |
|---|---|
| テーマ {#theme} | **システム** は Windows の設定に合わせます。**ダーク** か **ライト** も選べます。 |
| 比較 {#compare} | **DLSS 5 出力**、**オリジナル**、**ワイプ（境界をドラッグ）**、**モーションベクトル**、**深度** から選びます。 |
| ウィンドウに合わせる · 1:1 ピクセル {#fit} | 画像全体をウィンドウに収めるか、画像の 1 ピクセルを画面の 1 ピクセルで表示するかです。 |
| ズーム {#zoom} | 表示倍率です。画像の上でマウスホイールを回すとポインターの位置を中心に拡大縮小し、ドラッグで移動、ダブルクリックで全体表示に戻ります。 |
| 透明部分にチェッカーボード {#checkerboard} | 透明な部分をチェッカーボード模様で表示します。 |
| ライブラリを表示 {#show-library} | 画像の下にライブラリを表示します。 |
| オーバーレイ情報を表示 {#overlay} | サイズや状態を画像の上に表示します。 |
| ログを表示 {#show-log} | アプリのログをウィンドウ内に表示します。 |
| 起動時に前回のファイルを開く {#reopen-last} | 前回のセッションのファイルをもう一度開きます。最初はオフです。 |
| 垂直同期 {#vsync} | {adv} 画面の更新に合わせてウィンドウを描画します。 |
| 処理レート上限 {#rate-cap} | {adv} ライブモード：1 秒あたりに処理するフレーム数の上限です。最初は **オフ（すべてのフレーム）** です。カードに余力を残し、VRChat に回せます。 |

## MCP {#mcp}

MCP クライアントや別の PC のプログラムから、アプリを操作できるようにします。最初はオフです。[MCP](mcp.html)

![](sidebar-mcp "「MCP」セクション。")

| 設定 | 役割 |
|---|---|
| MCP サーバーを実行 {#mcp-run} | アプリが動いている間、サーバーを起動しておきます。 |
| 到達範囲 {#mcp-reach} | **この PC のみ**、またはクライアントごとに鍵を使う **ローカルネットワーク** です。 |
| ポート · 読み取り専用 {#mcp-port} | TCP ポートと、クライアントに閲覧だけを許すかどうかです。 |
| 鍵 · ジョブ {#mcp-keys} | 別の PC が使う鍵と、それらのジョブの順番待ちの列です。 |
