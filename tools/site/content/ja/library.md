開いた画像や動画はすべて、プレビューの下の **ライブラリ** に集まります。そこから多くのファイルを 1 回でまとめて処理できます。

![](library "5 つのファイルが入ったライブラリ。ボタンは右側にあります。")

## ファイルを追加する {#add}

- ファイルを開くか、ウィンドウにドロップすると、ライブラリに入ります。
- 複数のファイルやフォルダーごとドロップすると、すべて入ります。
- ライブラリの見出し行にある **ファイルを追加…** と **フォルダーを追加…** も使えます。

## 選択する {#select}

| 操作 | 結果 |
|---|---|
| サムネイルをクリック | そのファイルだけを選択します。 |
| ダブルクリック | プレビューで開きます。 |
| ((Ctrl)) + クリック | ファイルを 1 つ選択に加える、または選択から外します。 |
| ((Shift)) + クリック | 最後にクリックしたファイルからここまでを、すべて選択します。 |
| 何もない場所をドラッグ | 選択用の枠を描きます。 |
| ((Ctrl+A)) | すべてのファイルを選択します。 |
| ((Delete)) | 選択したファイルをライブラリから外します。 |

ライブラリから外しても、ディスク上のファイルが削除されることはありません。

## まとめて処理する {#batch}

1. ファイルを選んで **選択項目を処理** をクリックするか、**すべて処理** をクリックします。
   => ファイルが順番に処理されます。各サムネイルに進み具合のバーが表示され、終わったあとも状態が表示されたまま残ります。

画像と動画は、1 回の処理に混ぜられます。結果は、1 つずつ保存するときと同じフォルダーに同じ名前で保存されます。[保存先](saving.html)

## 1 つのファイルに個別の値を設定する {#own}

サムネイルを右クリックして **個別パラメーター…** を選ぶと、そのファイル専用の DLSS 5 の値を設定するウィンドウが開きます。複数のファイルを選んでいる場合は、同じメニューで全部にまとめて値を設定でき、その後は各ファイルが自分の値を持ちます。

同じメニューには **エクスプローラーで表示** と **ライブラリから外す** もあります。

## 回転・反転・切り抜き {#transform}

画像の上の小さなツールバーで、ライブラリのファイルをどう使うかを変えられます。

- **左に 90° 回転** と **右に 90° 回転**
- **左右反転** と **上下反転**
- **切り抜き**：枠の角や辺をドラッグします。枠の内側をドラッグすると枠が動きます。((Enter)) で適用、((Esc)) で取り消します。
- 最後のボタンは、ファイルを元の状態に戻します。

元のファイルは変更されません。プレビューと保存結果には回転・切り抜き後の画像が使われ、((Ctrl+Z)) で 1 ステップずつ元に戻せます。

> [!TIP]
> ツールバーは動かせます。左端のグリップをドラッグして移動するか、右端の矢印で画面の端に収納します。端に残る小さなタブで元に戻せます。
