MCP（Model Context Protocol）は、あるプログラムが別のプログラムを使うためのオープンな標準です。MCP を使うと、Claude Desktop、Claude Code、Cursor などの **MCP クライアント** が、ウィンドウと同じ操作で画像や動画を開き、設定を変え、ライブラリを処理し、撮影した画像を保存し、プレビューを確認できます。

クライアントが行った操作はウィンドウに表示され、((Ctrl+Z)) で元に戻せ、手で行った変更と同じように保存されます。

このページでは基本を説明します。すべてのツールと決まりは、GitHub の [docs/MCP.md](https://github.com/AlanBacker/VRChat-DLSS5-Cam/blob/main/docs/MCP.md) にあります。

## 最初から安全です {#default}

- サーバーは、オンにするまで動きません。
- オンにしても、待ち受けるのはこの PC（`127.0.0.1`）だけで、自分からどこかに接続することはありません。
- Web ページからのリクエストは拒否します。
- **読み取り専用** にすると、クライアントは閲覧だけができ、何も変更できません。

## この PC のクライアントを接続する {#local}

1. サイドバーで **MCP** を開き、**MCP サーバーを実行** をオンにします。
   => 状態の行にアドレスが表示されます。最初は `http://127.0.0.1:51550/mcp` です。
2. **クライアント設定をコピー** をクリックします。
3. MCP クライアントの設定に貼り付け、クライアントを再起動します。
   設定の場所は、Claude Desktop では Settings → Developer → Edit Config、Cursor では Settings → MCP → Add new server です。

この設定は `--mcp` を付けてアプリを起動します。これはクライアントのメッセージを中継するブリッジで、アプリが起動していなければアプリを起動します。

```json
{
  "mcpServers": {
    "vrchat-dlss5-cam": {
      "command": "C:\\Path\\To\\VRChatDLSS5Cam.exe",
      "args": ["--mcp"]
    }
  }
}
```

URL を受け付けるクライアントは、起動中のアプリに直接接続します。Claude Code の場合：

```
claude mcp add --transport http vrchat-dlss5-cam http://127.0.0.1:51550/mcp
```

## 別の PC から処理を送ってもらう {#remote}

強力なカードを積んだ 1 台の PC で、ほかの何台もの処理を引き受けられます。チャットボット、スクリプト、別の PC のクライアントが画像や動画を送り、順番を待って、結果を受け取ります。

1. **到達範囲** を **ローカルネットワーク** にし、**Windows ファイアウォールで許可** をクリックして、管理者権限の確認を承認します。
2. **鍵** でクライアントの名前を入力し、役割に **ジョブ** を選んで **鍵を追加** をクリックします。
   => 鍵がクリップボードにコピーされます。その鍵は、そのクライアントだけに渡してください。
3. 状態の行の下に表示されるアドレス（たとえば `http://192.168.1.20:51550/mcp`）をクライアントに伝えます。

| 役割 | できること |
|---|---|
| 閲覧 | 見るだけです。状態、設定、ログ、プレビュー、ライブラリ。 |
| ジョブ | ファイルを送り、自分のジョブの進み具合を確認して結果を受け取ります。それ以外はできません。 |
| 管理者 | ウィンドウでできることすべて。 |

> [!WARNING]
> ポートは家庭内のネットワークか VPN の中だけにとどめてください。サーバーは暗号化されていない HTTP で通信し、クライアントに必要なのは鍵だけです。ポートをインターネットに公開しないでください。

ジョブは、ウィンドウでのあなた自身の作業のあとに、1 つずつ実行されます。セクションの **ジョブ** には、待機中と実行中の数が表示されます。**結果の保持（時間）** では、完成したファイルをクライアントのために残しておく時間を設定します。
