你打开的每张图片或每个视频，都会收进预览下方的**素材库**。在这里可以一次处理多个文件。

![](library "有五个文件的素材库。按钮在右侧。")

## 添加文件 {#add}

- 打开一个文件，或者把它拖到窗口上：它会进入素材库。
- 拖入多个文件或整个文件夹：它们会全部进入素材库。
- 也可以使用素材库标题行中的**添加文件…**和**添加文件夹…**。

## 选择 {#select}

| 操作 | 结果 |
|---|---|
| 单击缩略图 | 只选中这个文件。 |
| 双击 | 在预览中打开它。 |
| ((Ctrl)) + 单击 | 加选或取消选择一个文件。 |
| ((Shift)) + 单击 | 选中从上次单击的文件到这里的所有文件。 |
| 在空白处拖动 | 拉出一个选择框。 |
| ((Ctrl+A)) | 选中所有文件。 |
| ((Delete)) | 把选中的文件移出素材库。 |

把文件移出素材库，并不会从磁盘上删除它。

## 一次处理多个 {#batch}

1. 选中文件后点击**处理选中**，或者直接点击**全部处理**。
   => 文件依次处理。每个缩略图上都有进度条，处理完后状态仍然保留。

同一批中可以混合图片和视频。结果的保存位置和文件名，都与单独保存时相同。[保存位置](saving.html)

## 为单个文件设置独立参数 {#own}

右键点击缩略图，选择**单独参数…**。随后会打开一个窗口，里面是只作用于这个文件的 DLSS 5 参数。选中多个文件时，这个菜单会为它们一起设置参数，之后每个文件各自保留一份。

同一个菜单中还有**在资源管理器中显示**和**从素材库移除**。

## 旋转、镜像与裁切 {#transform}

画面上的小工具条可以改变素材库文件的使用方式：

- **向左旋转 90°** 和 **向右旋转 90°**
- **水平翻转**和**垂直翻转**
- **裁切**：拖动裁切框的角和边，或者在框内拖动来移动它。((Enter)) 应用，((Esc)) 取消。
- 最后一个按钮把文件恢复原样。

原文件不会被改动。预览和保存的结果都使用旋转、裁切后的画面，((Ctrl+Z)) 可以逐步撤销。

> [!TIP]
> 工具条可以移动。按住它左端的手柄拖动，或者点击右端的箭头，把它收到边缘。边缘上的小标签可以把它重新展开。
