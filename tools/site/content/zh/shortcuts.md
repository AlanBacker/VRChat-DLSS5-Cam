## 通用 {#general}

| 按键 | 作用 |
|---|---|
| ((Ctrl+Alt+P)) {#hotkey} | 实时模式：拍照，即使 VRChat 在前台也有效。图片或视频模式：处理并保存。可以在**拍照** → **全局热键**中修改。 |
| ((Ctrl+Z)) {#undo} | 撤销上一次对设置或素材库的更改。 |
| ((Ctrl+Y)) · ((Ctrl+Shift+Z)) {#redo} | 重做。 |
| ((F11)) {#fullscreen} | 全屏显示画面。按 ((Esc)) 或 ((F11)) 退出。 |
| ((Tab)) · ((Shift+Tab)) {#tab} | 移到下一个或上一个控件。方向键永远不会在控件之间移动。 |
| 在搜索框中按 ((Esc)) {#search} | 清空搜索。 |

## 画面 {#picture}

| 鼠标 | 作用 |
|---|---|
| 在画面上滚动鼠标滚轮 {#wheel} | 以指针为中心缩放。 |
| 拖动画面 {#drag} | 在放大后的画面中四处移动。 |
| 双击 {#double-click} | 回到完整画面。 |
| 拖动白线 {#wipe} | 移动分隔线（在**分割对比**视图中）。 |
| 裁切时按 ((Enter)) · ((Esc)) {#crop} | 应用裁切，或者取消。 |

## 视频 {#video}

| 按键 | 作用 |
|---|---|
| ((Space)) {#play} | 播放或暂停。 |
| ((←)) · ((→)) {#step} | 后退或前进一帧。按住 ((Shift))：十帧。 |
| ((Home)) · ((End)) {#ends} | 跳到开头或结尾。 |
| ((I)) · ((O)) {#range} | 设置要保存的片段的起点或终点。 |

## 素材库 {#library}

| 操作 | 作用 |
|---|---|
| 单击缩略图 {#click} | 只选中这个文件。 |
| 双击缩略图 {#open} | 在预览中打开它。 |
| ((Ctrl)) + 单击 {#ctrl-click} | 把一个文件加入选择，或从选择中去掉。 |
| ((Shift)) + 单击 {#shift-click} | 从上次单击的位置起扩展选择。 |
| 在空白处拖动 {#marquee} | 拉出一个选择框。单击空白处会取消选择。 |
| 在缩略图上按右键 {#menu} | 文件的菜单：单独参数、在资源管理器中显示、移除。 |
| ((Ctrl+A)) {#select-all} | 选中所有文件（鼠标位于素材库上时）。 |
| ((Delete)) {#delete} | 把选中的文件移出素材库。文件仍保留在磁盘上。 |

## 布局 {#layout}

| 操作 | 作用 |
|---|---|
| 单击侧栏旁或素材库上方的空隙 {#fold} | 折叠或展开那个面板。 |
| 拖动空隙边缘的细线 {#resize} | 改变侧栏的宽度或素材库的高度。程序会记住这两个尺寸。 |
