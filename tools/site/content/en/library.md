Every picture or video you open is collected in the **library** under the preview. From there you can process many files in one run.

![](library "The library with five files. Its buttons are on the right.")

## Add files {#add}

- Open a file, or drop it on the window: it goes into the library.
- Drop several files or a whole folder: they all go in.
- Or use **Add files...** and **Add folder...** in the library's header.

## Select {#select}

| Do this | What happens |
|---|---|
| Click a thumbnail | Selects that file alone. |
| Double-click | Opens it in the preview. |
| ((Ctrl)) + click | Adds or removes one file. |
| ((Shift)) + click | Selects everything from the last click to here. |
| Drag over empty space | Draws a selection box. |
| ((Ctrl+A)) | Selects every file. |
| ((Delete)) | Takes the selected files out of the library. |

Taking a file out of the library never deletes it from your disk.

## Process many at once {#batch}

1. Select the files and click **Process selected**, or click **Process all**.
   => The files run one after another. Each thumbnail shows a progress bar, and its state stays visible afterwards.

Pictures and videos can be mixed in one run. The results go to the same folder, with the same names, as a single save. [Saving](saving.html)

## Own values for one file {#own}

Right-click a thumbnail and choose **Own parameters...** to open a window with the DLSS 5 values for that file only. With several files selected, the menu sets the values for all of them, and each keeps its own copy afterwards.

The same menu has **Show in Explorer** and **Remove from the library**.

## Turn, mirror and crop {#transform}

A small toolbar over the picture changes how a library file is used:

- **Turn left (90°)** and **Turn right (90°)**
- **Mirror left-right** and **Mirror top-bottom**
- **Crop**: drag the corners and edges of the frame, or drag inside it to move it. ((Enter)) applies, ((Esc)) cancels.
- The last button puts the file back as it comes.

Your original file is not changed. The preview and the saved result use the turned and cropped picture, and ((Ctrl+Z)) undoes each step.

> [!TIP]
> The toolbar can move. Drag it by the grip at its left end, or tuck it away at an edge with the arrow at its right end. A small tab brings it back.
