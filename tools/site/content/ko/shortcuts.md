## 어디서나 {#general}

| 키 | 동작 |
|---|---|
| ((Ctrl+Alt+P)) {#hotkey} | 라이브: VRChat이 앞에 있어도 사진을 저장합니다. 이미지·동영상: 처리하고 저장합니다. **촬영** → **전역 단축키**에서 바꿀 수 있습니다. |
| ((Ctrl+Z)) {#undo} | 설정이나 라이브러리의 마지막 변경을 되돌립니다. |
| ((Ctrl+Y)) · ((Ctrl+Shift+Z)) {#redo} | 다시 실행합니다. |
| ((F11)) {#fullscreen} | 이미지를 전체 화면으로 봅니다. ((Esc))나 ((F11))을 누르면 빠져나옵니다. |
| ((Tab)) · ((Shift+Tab)) {#tab} | 다음 컨트롤이나 이전 컨트롤로 이동합니다. 화살표 키로는 컨트롤 사이를 이동하지 않습니다. |
| 검색 칸에서 ((Esc)) {#search} | 검색어를 지웁니다. |
| AI Q&A 패널에서 ((Esc)) {#ask} | 패널을 닫습니다. [AI Q&A](ai-qa.html) |

## 이미지 {#picture}

| 마우스 | 동작 |
|---|---|
| 이미지 위에서 마우스 휠 {#wheel} | 포인터를 중심으로 확대·축소합니다. |
| 이미지 드래그 {#drag} | 확대한 이미지를 옮겨 가며 봅니다. |
| 더블클릭 {#double-click} | 전체 이미지로 돌아갑니다. |
| 흰 선 드래그 {#wipe} | 비교선을 옮깁니다(**와이프** 보기에서). |
| 자르는 중 ((Enter)) · ((Esc)) {#crop} | 자르기를 적용하거나 취소합니다. |

## 동영상 {#video}

| 키 | 동작 |
|---|---|
| ((Space)) {#play} | 재생하거나 일시 정지합니다. |
| ((←)) · ((→)) {#step} | 한 프레임 뒤로 또는 앞으로 이동합니다. ((Shift))를 함께 누르면 열 프레임씩 이동합니다. |
| ((Home)) · ((End)) {#ends} | 처음이나 끝으로 이동합니다. |
| ((I)) · ((O)) {#range} | 저장할 구간의 시작점이나 끝점을 정합니다. |

## 라이브러리 {#library}

| 이렇게 하면 | 동작 |
|---|---|
| 썸네일 클릭 {#click} | 그 파일만 선택합니다. |
| 썸네일 더블클릭 {#open} | 미리보기에서 엽니다. |
| ((Ctrl)) + 클릭 {#ctrl-click} | 파일 하나를 선택에 더하거나 뺍니다. |
| ((Shift)) + 클릭 {#shift-click} | 마지막으로 클릭한 파일부터 선택을 넓힙니다. |
| 빈 곳에서 드래그 {#marquee} | 선택 상자를 그립니다. 빈 곳을 클릭하면 선택이 풀립니다. |
| 썸네일에서 마우스 오른쪽 버튼 {#menu} | 파일 메뉴: 개별 매개변수, 탐색기에서 표시, 제거. |
| ((Ctrl+A)) {#select-all} | 모든 파일을 선택합니다(마우스가 라이브러리 위에 있을 때). |
| ((Delete)) {#delete} | 선택한 파일을 라이브러리에서 뺍니다. 파일은 디스크에 남습니다. |

## 레이아웃 {#layout}

| 이렇게 하면 | 동작 |
|---|---|
| 사이드바 옆이나 라이브러리 위의 틈 클릭 {#fold} | 그 패널을 접거나 펼칩니다. |
| 틈 가장자리의 가는 선 드래그 {#resize} | 사이드바 너비나 라이브러리 높이를 바꿉니다. 앱이 둘 다 기억합니다. |
