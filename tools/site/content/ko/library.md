연 이미지와 동영상은 모두 미리보기 아래의 **라이브러리**에 모입니다. 여기서 여러 파일을 한 번에 처리할 수 있습니다.

![](library "파일 다섯 개가 들어 있는 라이브러리. 오른쪽에 버튼이 있습니다.")

## 파일 추가하기 {#add}

- 파일을 열거나 창에 끌어다 놓으면 라이브러리에 들어갑니다.
- 여러 파일이나 폴더 전체를 끌어다 놓으면 모두 들어갑니다.
- 라이브러리 머리글의 **파일 추가…**와 **폴더 추가…**를 써도 됩니다.

## 선택하기 {#select}

| 이렇게 하면 | 결과 |
|---|---|
| 썸네일 클릭 | 그 파일만 선택합니다. |
| 더블클릭 | 미리보기에서 엽니다. |
| ((Ctrl)) + 클릭 | 파일 하나를 선택에 더하거나 뺍니다. |
| ((Shift)) + 클릭 | 마지막으로 클릭한 파일부터 여기까지 모두 선택합니다. |
| 빈 곳에서 드래그 | 선택 상자를 그립니다. |
| ((Ctrl+A)) | 모든 파일을 선택합니다. |
| ((Delete)) | 선택한 파일을 라이브러리에서 뺍니다. |

라이브러리에서 파일을 빼도 디스크에서 지워지지는 않습니다.

## 여러 파일을 한 번에 처리하기 {#batch}

1. 파일을 선택하고 **선택 항목 처리**를 클릭하거나, **모두 처리**를 클릭합니다.
   => 파일이 차례로 처리됩니다. 썸네일마다 진행률 막대가 표시되고, 끝난 뒤에도 상태가 계속 보입니다.

이미지와 동영상을 섞어서 한 번에 처리할 수 있습니다. 결과는 하나씩 저장할 때와 같은 폴더에 같은 이름으로 저장됩니다. [저장 위치](saving.html)

## 파일 하나에만 따로 값 주기 {#own}

썸네일을 마우스 오른쪽 버튼으로 클릭하고 **개별 매개변수…**를 고르면, 그 파일에만 적용되는 DLSS 5 값을 정하는 창이 열립니다. 여러 파일을 선택한 상태라면 이 메뉴로 모든 파일의 값을 한꺼번에 정하고, 그 뒤에는 파일마다 자기 사본을 따로 가집니다.

같은 메뉴에 **탐색기에서 표시**와 **라이브러리에서 제거**도 있습니다.

## 회전, 반전, 자르기 {#transform}

이미지 위의 작은 도구 모음으로 라이브러리 파일을 어떻게 쓸지 바꿀 수 있습니다.

- **왼쪽으로 90° 회전**과 **오른쪽으로 90° 회전**
- **좌우 반전**과 **상하 반전**
- **자르기**: 틀의 모서리와 가장자리를 드래그하거나, 틀 안쪽을 드래그해 옮깁니다. ((Enter))로 적용하고 ((Esc))로 취소합니다.
- 마지막 버튼은 파일을 원래 상태로 되돌립니다.

원본 파일은 바뀌지 않습니다. 미리보기와 저장 결과에는 회전하고 잘라 낸 이미지가 쓰이며, ((Ctrl+Z))로 한 단계씩 되돌릴 수 있습니다.

> [!TIP]
> 도구 모음은 옮길 수 있습니다. 왼쪽 끝의 손잡이를 잡고 드래그하거나, 오른쪽 끝의 화살표로 가장자리에 접어 둘 수 있습니다. 작은 탭을 누르면 다시 나타납니다.
