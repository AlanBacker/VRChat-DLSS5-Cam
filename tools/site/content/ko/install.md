## 필요한 것 {#requirements}

- Windows 10(21H2 이상) 또는 Windows 11, 64비트.
- NVIDIA GeForce RTX 카드: RTX 20, 30, 40, 50 시리즈.
  AMD Radeon RX 7000이나 9000은 [Radeon 에디션](radeon.html)으로 쓸 수 있습니다.
- 실시간 카메라를 쓰려면 VRChat(데스크톱 또는 VR).

그 밖에는 필요 없습니다. DLSS 5 런타임은 다운로드에 들어 있으며, RTX 50용 빌드와 RTX 40, 30, 20용 빌드가 하나씩 있습니다. 앱이 맞는 빌드를 알아서 고릅니다.

## 내려받기와 압축 풀기 {#package}

1. [다운로드 섹션](index.html#download)을 열고 내 카드에 맞는 파일을 고릅니다.
   GeForce 카드라면 `VRChatDLSS5Cam-win64.zip`입니다.
2. zip 파일을 마우스 오른쪽 버튼으로 클릭하고 **모두 압축 풀기**를 선택합니다. 압축을 풀 곳으로 **문서**처럼 내 계정의 폴더를 고릅니다.
   => `VRChatDLSS5Cam.exe`가 들어 있는 새 폴더가 생깁니다.
3. `VRChatDLSS5Cam.exe`를 더블클릭합니다.
   => 앱 아이콘이 있는 작은 카드가 나타나고, 이어서 창이 열립니다.

> [!WARNING]
> zip 파일 안에서 바로 앱을 실행하지 말고, `Program Files` 아래에도 두지 마세요. 앱은 자기 파일을 바꿔서 스스로 업데이트하는데, 관리자 권한이 필요한 폴더에서는 그렇게 할 수 없습니다.

> [!NOTE]
> 앱은 유료 인증서로 서명되어 있지 않아서, Windows가 PC를 보호했다는 파란 창을 띄울 수 있습니다. **추가 정보**를 클릭한 다음 **실행**을 클릭하세요. 소스 코드는 GitHub에 공개되어 있습니다.

## 설정 가이드 {#setup-guide}

처음 실행하면 다섯 페이지로 된 짧은 설정 가이드가 열립니다.

1. **환영합니다**: 언어와 화면 모양(**시스템**, **다크**, **라이트**).
2. **GitHub 접속 방식**: 업데이트를 위해 앱이 GitHub에 연결하는 방법입니다. **GitHub에 직접 연결**을 그대로 두세요. GitHub가 느리거나 막혀 있는 곳에서는 **미러 사이트(가장 빠른 곳 자동 선택)**를 고르세요.
3. **프로그램 동작 방식**
4. **각 설정의 역할**
5. **어디에 무엇이 있는지**

**다음**으로 넘어가고, **건너뛰기**로 닫습니다. 나중에 다시 보려면 **정보** → **설정 가이드**를 누르세요.

## 그래픽 드라이버 {#driver}

DLSS 5에는 GeForce 드라이버 **616.56** 이상이 필요합니다. 앱은 시작할 때마다 드라이버를 확인하고, 드라이버가 그보다 오래되었으면 알려 줍니다.

![](driver-notice)

1. **드라이버 다운로드**를 클릭합니다. 브라우저에서 NVIDIA 다운로드 페이지가 열립니다.
2. 내 카드에 맞는 최신 드라이버를 설치합니다.
3. 앱을 다시 실행합니다.
   => 알림이 더 이상 나타나지 않고, **DLSS 5 뉴럴 렌더링**에 **동작 중**이 표시됩니다.

드라이버가 오래되어도 나머지 기능은 그대로 동작합니다. 뷰어, 촬영, 동영상 모두 쓸 수 있고, DLSS 5만 시작되지 않습니다.

> [!TIP]
> 알림의 **다시 표시하지 않음**을 누르면 확인이 꺼집니다. **정보** → **시작 시 드라이버 확인**으로 다시 켤 수 있습니다.
